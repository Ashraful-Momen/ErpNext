# Chapter 2 : DocType কী?

DocType = Database Table-এর Definition (Schema)।

```
Account (DocType)       → tabAccount (Table)
GL Entry (DocType)      → tabGL Entry (Table)
Sales Invoice (DocType) → tabSales Invoice (Table)
```

> **প্রতিটা DocType = একটা `tab` prefix-এর MySQL Table।**

# Chapter 4 : CRUD — Document তৈরি, পড়া, Submit

```python
# তৈরি + Save (Draft)
doc = frappe.get_doc({
    "doctype": "Journal Entry",
    "company": "Ashraful Tech Ltd",
    "posting_date": "2026-07-01",
    "voucher_type": "Journal Entry",
    "accounts": [
        {"account": "Bank", "debit_in_account_currency": 10000},
        {"account": "Capital", "credit_in_account_currency": 10000},
    ],
})
doc.insert()      # Save as Draft
doc.submit()      # Post → GL Entry তৈরি
```

```python
# পড়া
doc = frappe.get_doc("Sales Invoice", "SI-0001")
print(doc.customer, doc.grand_total)

# Cancel
doc.cancel()      # GL Entry reverse
```

# Chapter 5 : Submit-এর ভিতরে কী হয় (GL Entry Generation)

```
doc.submit()
    │
    ▼
Validate (Difference = 0 ইত্যাদি)
    │
    ▼
GL Entry তৈরি (debit/credit, voucher, party)
    │
    ▼
Party Balance / Outstanding Update
```

> **Frappe-তে `doc.submit()`-এর ভিতরে `make_gl_entries()`-এর মতো method চলে — যেটা GL Entry বানায়।**

# Chapter 6 : Database Query (frappe.db.sql)

```python
# Account Balance
balance = frappe.db.sql("""
    SELECT SUM(debit) - SUM(credit)
    FROM `tabGL Entry`
    WHERE account = %s AND company = %s AND is_cancelled = 0
""", ("Bank", "Ashraful Tech Ltd"))

# Customer-এর মোট পাওনা
frappe.db.sql("""
    SELECT SUM(debit) - SUM(credit)
    FROM `tabGL Entry`
    WHERE account = 'Debtors' AND party = %s AND is_cancelled = 0
""", "Customer A")
```

> **Backtick `\`tabGL Entry\`` — table name-এ space আছে বলে backtick দিতে হয়।**

# Chapter 7 : hooks.py কী?

Frappe App-এর Configuration file — এখানে event handler, scheduled task, doc_events declare হয়।

```python
# hooks.py
doc_events = {
    "Sales Invoice": {
        "on_submit": "myapp.events.send_notification"
    }
}

scheduler_events = {
    "daily": [
        "myapp.tasks.daily_report"
    ]
}
```

# Chapter 9 : Developer-এর ৩টা Golden Rule

1. **GL Entry কখনো হাতে Edit করো না** — Document দিয়ে করো।
2. **সব Query-তে `is_cancelled = 0` + `company` Filter**।
3. **`insert()` = Save (Draft), `submit()` = Post, `cancel()` = Reverse**।

# Interview Questions

1. **Frappe Framework কী?** — ERPNext-এর base; Python + MariaDB।
2. **DocType আর Table-এর সম্পর্ক?** — DocType = Schema, Table = `tab` prefix-এর MySQL Table।
3. **`submit()` কী করে?** — GL Entry তৈরি করে, Post করে।
4. **GL Entry কীভাবে Query করবে?** — `frappe.db.sql` দিয়ে `tabGL Entry`।
5. **hooks.py কী?** — App-এর event/scheduler configuration।
6. **GL Entry হাতে Edit করা উচিত?** — না, সবসময় Document দিয়ে।

# Common Mistakes

❌ GL Entry হাতে Edit/Delete
❌ `is_cancelled = 0` Filter ভুলে যাওয়া
❌ `insert()` দিয়ে Post করার আশা (submit দরকার)
❌ Table name-এ backtick না দেওয়া
❌ company Filter না দেওয়া
