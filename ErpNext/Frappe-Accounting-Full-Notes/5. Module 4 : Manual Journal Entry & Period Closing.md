# Module 4: Manual Journal Entry & Period Closing Voucher

আজ আমরা **হাতে কলমে Journal Entry** লিখব, আর শিখব বছরের শেষে **কীভাবে Account বন্ধ (Close) করা হয়**।

> **Odoo-র "Journal Voucher"-এর ERPNext সংস্করণই হলো Period Closing Voucher — বছর শেষে সব Temporary Account (Income/Expense) বন্ধ করে Profit-এ পরিণত করে।**

---

# Chapter 1 : Real Life Story

মাস শেষে Accountant বসে বসে কিছু Entry হাতে লেখে:

* Utility Bill এসেছে, এখনো দেয়া হয়নি → Accrual Entry
* আগে থেকে রেন্ট দেয়া → Prepaid Entry
* বছরের Opening Balance ঢোকানো → Opening Entry

এই সব Manual Entry-র জন্যই **Journal Entry**।

আর ৩১ ডিসেম্বর রাতে Accountant সব Income আর Expense Account-এর Balance শূন্য করে **Profit & Loss**-এ নিয়ে যায় — সেটাই **Period Closing**।

---

# Chapter 2 : Manual Journal Entry-র বাস্তব Scenario

## Scenario 1 : মাসের Salary Accrue (কিন্তু এখনো দেয়া হয়নি)

```
Debit  Salary Expense   50,000   (Expense বাড়ল)
Credit Salary Payable   50,000   (Liability বাড়ল)
```

> দিলে পরে: `Debit Salary Payable / Credit Bank`।

## Scenario 2 : রেন্ট আগে থেকেই দেয়া (Prepaid)

```
Debit  Prepaid Rent     12,000   (Asset — এখনো ভোগ হয়নি)
Credit Bank             12,000
```

## Scenario 3 : বছরের Opening Balance

```
Debit  Bank              1,00,000
Credit Opening Balance Equity 1,00,000
```

> Opening-এর জন্য Journal Entry Type = `Opening Entry` দেবে। এতে `is_opening = 1` হয়ে যায়।

# Chapter 3 : ERPNext-এ Manual Journal Entry লেখার ধাপ

```
১. Accounting → Journal Entry → New
২. Company select
৩. Voucher Type select (Journal Entry / Bank Entry / Cash Entry)
৪. Posting Date দিন
৫. Accounts table-এ Account + Debit/Credit + (Party, Cost Center) দিন
৬. Difference = 0 দেখো
৭. Save → Submit
```

> Submit করলেই GL Entry তৈরি হয়ে General Ledger-এ চলে যাবে।

# Chapter 4 : Journal Entry Type আরও গভীরে

| Voucher Type | কখন | GL Entry-র প্রভাব |
| ------------ | ---- | ----------------- |
| Journal Entry | সাধারণ | Account-ভিত্তিক Dr/Cr |
| Bank Entry | Bank জড়িত | Bank Account Dr/Cr |
| Cash Entry | Cash জড়িত | Cash Account Dr/Cr |
| Contra Entry | Bank ↔ Cash | এক Bank Dr, আরেক Cash Cr |
| Opening Entry | বছরের শুরু | is_opening = 1 |
| Depreciation Entry | Asset-এর অবচয় | Dr Depreciation / Cr Accumulated Depreciation |
| Exchange Rate Revaluation | Currency হার বদল | Dr/Cr Exchange Gain/Loss |
| Inter Company Journal Entry | Company A ↔ Company B | দুই Company-র GL Entry |
| Reversal Journal Entry | উল্টো | আগের Entry reverse |

# Chapter 5 : Period Closing Voucher (বছর শেষে)

**Period Closing Voucher** ERPNext-এর সেই Document যা বছরের শেষে Temporary Account বন্ধ করে।

```
Income Account (Sales)      → Profit & Loss Account-এ বন্ধ
Expense Account (Salary...) → Profit & Loss Account-এ বন্ধ
Profit & Loss Account       → Retained Earnings-এ Transfer
```

**কেন দরকার?** Income/Expense বছরের শেষে শূন্য (Zero) হয়ে নতুন বছরে নতুন করে শুরু হয়।

---

# Chapter 6 : Period Closing Voucher-এর Flow

```
৩১ ডিসেম্বর রাতে
        │
        ▼
Period Closing Voucher (Accounting → Period Closing Voucher)
        │
        ▼
Temporary Account বন্ধ (Income/Expense → P&L)
        │
        ▼
P&L → Retained Earnings (Equity-র ভিতরে)
        │
        ▼
নতুন বছরে Income/Expense শূন্য থেকে শুরু
```

> **Odoo-র মতো ERPNext-ও "close" করলে পুরনো বছরের Entry লক হয়ে যায় না (সাধারণত), কিন্তু Report ঠিক রাখতে Period Closing Voucher ব্যবহার হয়।**

# Chapter 8 : Developer Perspective

Opening Entry তৈরি:

```python
je = frappe.get_doc({
    "doctype": "Journal Entry",
    "voucher_type": "Opening Entry",
    "company": "Ashraful Tech Ltd",
    "posting_date": "2026-01-01",
    "accounts": [
        {"account": "Bank", "debit_in_account_currency": 100000},
        {"account": "Opening Balance Equity", "credit_in_account_currency": 100000},
    ],
})
je.insert()
je.submit()
```

Period Closing-এর আসল কাজ (Concept — ERPNext নিজে করে):

```sql
-- Income/Expense-এর Balance P&L-এ Transfer
SELECT account, SUM(debit - credit) FROM `tabGL Entry`
WHERE root_type IN ('Income', 'Expense') GROUP BY account;
```

# Interview Questions

1. **Manual Journal Entry কখন দরকার?** — Invoice/Payment-এর বাইরে Accrual, Prepaid, Opening, Adjustment-এর জন্য।
2. **Opening Entry কীভাবে চেনা যায়?** — `is_opening = 1`, Voucher Type `Opening Entry`।
3. **Period Closing Voucher কী করে?** — বছরের শেষে Income/Expense বন্ধ করে P&L → Retained Earnings।
4. **Contra Entry কী?** — Bank ↔ Cash নিজের টাকা Transfer।
5. **Submit না করলে কী হয়?** — GL Entry হয় না, Report-এ আসে না।

---

# Common Mistakes

❌ Opening Balance সাধারণ Journal Entry দিয়ে ঢোকানো (Opening Entry Type দেবে)
❌ Accrual Entry না দিয়ে Report-এ খরচ না দেখানো
❌ Period Closing আগে থেকে করা — Report-এর Period ভুল
❌ Group Account-এ Entry
❌ Difference শূন্য না করে Save

# Cheat Sheet

```
Manual Adjustment?
        │
        ├── Accrual      → Dr Expense / Cr Payable
        ├── Prepaid      → Dr Prepaid / Cr Bank
        ├── Opening      → Dr Asset / Cr Equity (Opening Entry)
        └── Contra       → Dr Bank / Cr Cash
                │
                ▼
        Journal Entry Submit
                │
                ▼
           GL Entry

Year End:
        │
        ▼
Period Closing Voucher → Income/Expense → P&L → Retained Earnings
```
