# Module 12: Reports — ERPNext Complete Note

আজ শিখব **Financial Reports** — Trial Balance, General Ledger, Profit & Loss, Balance Sheet, AR/AP — সবকিছু কীভাবে GL Entry থেকে আসে।

> **Odoo-র Reporting-এর ERPNext সংস্করণ: সব Report একটাই উৎস থেকে — `tabGL Entry`। Report আলাদা Table না, শুধু Query।**

---

# Chapter 1 : Report-এর মূল ধারণা

```
GL Entry (tabGL Entry)  ──►  সব Report-এর একটাই উৎস
```

```
Trial Balance   → Account-ভিত্তিক Dr/Cr Sum
General Ledger  → প্রতিটা Account-র প্রতিটা লেনদেন
P&L             → Income − Expense
Balance Sheet   → Assets = Liabilities + Equity
Accounts Receivable → Customer-এর মোট পাওনা
Accounts Payable    → Supplier-এর মোট দেনা
```

---

# Chapter 2 : Trial Balance

প্রতিটা Account-এর মোট Debit আর Credit Balance দেখায়।

```
Account             Debit        Credit
Bank               100,000
Cash                20,000
Sales                            50,000
Salary Expense      10,000
─────────────────────────────────────────
Total              130,000       130,000   ✅ (Dr = Cr)
```

> **Trial Balance-এ মোট Debit = মোট Credit হলে Double Entry সঠিক। না হলে কোথাও ভুল আছে।**

---

# Chapter 3 : General Ledger

একটা নির্দিষ্ট Account-এর প্রতিটা লেনদেন (GL Entry) দেখায়।

```
Account: Bank
Date        Voucher        Dr          Cr
01 Jul      JV-0001        100,000
05 Jul      PE-0001                      2,000
```

> **General Ledger = Account-এর "ডায়েরি"।**

---

# Chapter 4 : Profit & Loss (Income Statement)

কোম্পানি **Profit করছে নাকি Loss** — সেটা দেখায়।

```
Income
   Sales                      50,000
─────────────────────────────────────
Total Income                  50,000
Expenses
   Salary                      10,000
   Rent                         5,000
─────────────────────────────────────
Total Expense                 15,000
─────────────────────────────────────
Net Profit                    35,000
```

> **Net Profit = Income − Expense। Root Type Income/Expense-এর Account-ই এখানে আসে।**

---

# Chapter 5 : Balance Sheet

কোম্পানির **আর্থিক অবস্থা** (এক নির্দিষ্ট দিনে) দেখায়।

```
Assets
   Bank                       100,000
   Cash                        20,000
   Stock                       30,000
   Fixed Asset                 40,000
Total Assets                  190,000

Liabilities
   Creditors                   40,000
Equity
   Capital                    100,000
   Retained Earnings           50,000
Total Liab + Equity           190,000   ✅ (Assets = Liab + Equity)
```

> **Root Type Asset/Liability/Equity-এর Account-ই এখানে আসে।**

---

# Chapter 6 : Accounts Receivable & Payable

```
Accounts Receivable (AR) → প্রতিটা Customer-এর কত পাওনা
Accounts Payable (AP)    → প্রতিটা Supplier-কে কত দেনা
```

> **Receivable/Payable Account-এর Party-ভিত্তিক Balance (GL Entry-তে party field)।**

---

# Chapter 7 : Report-এর Filter

প্রতিটা Report-এ common Filter:

```
Company
From Date / To Date   → কোন Period
Fiscal Year
(Group By, Currency)
```

> **Posting Date-র ভিত্তিতে Report-এ Period ধরা হয়। আর সবসময় is_cancelled = 0 Entry-ই আসে।**

---

# Chapter 8 : Database (Frappe DocType)

```
GL Entry (tabGL Entry)  → সব Report-এর Source
```

Developer Report Query (Trial Balance):

```python
frappe.db.sql("""
    SELECT account,
           SUM(debit) AS total_debit,
           SUM(credit) AS total_credit
    FROM `tabGL Entry`
    WHERE company = %s AND posting_date BETWEEN %s AND %s
      AND is_cancelled = 0
    GROUP BY account
""", (company, from_date, to_date))
```

# Interview Questions

1. **Trial Balance-এ Dr = Cr কেন?** — Double Entry-র কারণে প্রতিটা Transaction-এ Dr = Cr।
2. **P&L-এ কোন Account আসে?** — Income আর Expense।
3. **Balance Sheet-এ কোন Account আসে?** — Asset, Liability, Equity।
4. **Report-গুলো কোথা থেকে আসে?** — GL Entry থেকে।
5. **AR আর AP কী?** — Customer-এর পাওনা (Receivable), Supplier-এর দেনা (Payable)।

---

# Common Mistakes

❌ Draft Document Report-এ আসবে ভাবা
❌ ভুল Posting Date দিয়ে Period গুলিয়ে ফেলা
❌ is_cancelled = 0 Filter ভুলে যাওয়া
❌ P&L আর Balance Sheet-এর Account গুলিয়ে ফেলা
❌ Trial Balance না মিললেও Report দেখানো
