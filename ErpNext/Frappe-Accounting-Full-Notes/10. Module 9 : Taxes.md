# Module 9: Taxes — ERPNext Complete Note

আজ শিখব **VAT/Sales Tax, Input Tax, Output Tax, আর Tax Withholding (TDS)** — কীভাবে ERPNext-এ Tax ধরা হয়।

> **Odoo-র Tax-এর ERPNext সংস্করণ: Sales/Purchase Taxes and Charges Template + Tax Category + Account (Account Type = Tax)।**

---

# Chapter 1 : Tax কী?

সরকারকে দেওয়া/নেওয়া Tax। Accounting-এ Tax নিজে Expense নয়, বরং **Collection** — তুমি Customer-এর কাছ থেকে VAT Collect করো, আর সরকারকে Pay করো।

```
Output VAT (Sales-এ) → Customer-এর কাছ থেকে নাও → Cr VAT Payable
Input VAT (Purchase-এ) → Supplier-কে দাও → Dr Input VAT (recoverable)
```

---

# Chapter 2 : ERPNext-এ Tax Setup-এর ৪টা জিনিস

```
১. Account          → Account Type = Tax (যেমন VAT Payable, Input VAT)
২. Tax Category     → ভিন্ন VAT Rate-এর জন্য
৩. Sales/Purchase Taxes and Charges Template → কোন Tax, কত %, কোন Account
৪. Tax Withholding Category → Supplier-এর Payment থেকে TDS কাটা
```

---

# Chapter 3 : Sales Taxes and Charges Template

```
Sales Taxes and Charges Template:
├── Charge Type     → On Net Total / On Previous Row Total
├── Account Head    → VAT Payable
├── Rate            → 15%
└── Description     → VAT @ 15%
```

Sales Invoice-তে এই Template দিলে:

```
Net Total $5,000 + VAT 15% ($750) = Grand Total $5,750
```

---

# Chapter 4 : Sales Invoice-এ VAT-এর GL Entry

Customer-কে $5,000 বিক্রি, VAT 15%:

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Debtors | 5,750 | |
| Sales | | 5,000 |
| VAT Payable | | 750 |

> **VAT Payable-এ $750 জমা হলো — এটা তুমি সরকারকে দেবে।**

---

# Chapter 5 : Purchase Invoice-এ Input VAT

Supplier থেকে $2,000 কেনা, VAT 15%:

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Office Equipment (Expense) | 2,000 | |
| Input VAT (Tax) | 300 | |
| Creditors | | 2,300 |

> **Input VAT $300 — এটা recoverable, Output VAT-এর সাথে adjust হয়।**

---

# Chapter 6 : Output VAT − Input VAT = Payable

```
Output VAT (Sales থেকে)   = 750
Input VAT (Purchase থেকে) = 300
─────────────────────────────────
VAT Payable (সরকারকে দিতে হবে) = 450
```

> **শেষে `Dr VAT Payable / Cr Bank` দিয়ে সরকারকে Payment করো।**

---

# Chapter 7 : Tax Withholding (TDS)

Supplier-কে Payment করার সময় কিছু % Tax কেটে রেখে সরকারে জমা দেওয়া হয় — **Tax Withholding**।

```
Supplier Bill $1,000, TDS 5% = $50
Payment Entry:
  Dr Creditors     1,000
  Cr Bank           950
  Cr TDS Payable     50
```

> **Tax Withholding Category দিয়ে কোন Rate-এ কাটা হবে সেটা ঠিক হয়।**

# Interview Questions

1. **Output VAT আর Input VAT-এর পার্থক্য?** — Output = Sales-এ Customer থেকে নেওয়া; Input = Purchase-এ Supplier-কে দেওয়া।
2. **VAT Payable কীভাবে হিসাব হয়?** — Output VAT − Input VAT।
3. **Charge Type "On Net Total" কী?** — Net Total-এর উপর % ধরা।
4. **Tax Withholding কী?** — Payment থেকে TDS কেটে সরকারে জমা দেওয়া।
5. **Tax Account-এর Account Type কী?** — `Tax`।

---

# Common Mistakes

❌ Tax Account-এ Account Type `Tax` না দেওয়া
❌ Input VAT আর Expense গুলিয়ে ফেলা
❌ Tax Template-এ ভুল Rate
❌ Output − Input adjust না করা
❌ TDS না কেটে পুরো Payment দেওয়া

---

# Cheat Sheet

```
Sales Invoice  → Cr VAT Payable (Output)
Purchase Invoice → Dr Input VAT
        │
        ▼
VAT Payable = Output − Input
        │
        ▼
Payment to Govt → Dr VAT Payable / Cr Bank
```
