# Module 8: Vendor & Purchase Invoice — ERPNext Complete Note

আজ শিখব **Vendor (Supplier) থেকে কেনা** — Purchase Invoice, Debit Note, Purchase Receipt, আর এর GL Entry।

> **Odoo-র Vendor Bill-এর ERPNext সংস্করণ `Purchase Invoice`। Submit করলে GL Entry: Dr Expense/Stock / Cr Creditors (+ Tax)।**

---

# Chapter 1 : Vendor (Supplier / Party) কী?

`Supplier` DocType = যার কাছ থেকে তুমি কেনো।

```
Supplier (tabSupplier)
├── Supplier Name
├── Supplier Group
├── Supplier Type (Company/Individual)
└── Default Currency / Payment Terms
```

> **Supplier-এর দেনা Accounts Payable (Creditors) Account-এ জমা হয়।**

---

# Chapter 2 : Purchase Invoice কী?

Supplier-এর কাছ থেকে কেনার Bill/Document। এটাই Expense (বা Stock) তৈরি করে।

```
Purchase Invoice (tabPurchase Invoice)
├── Supplier
├── Posting Date / Due Date
├── Items (child: Purchase Invoice Item)
├── Taxes and Charges
├── Update Stock (checkbox)
└── Payment Terms
```

**Purchase Invoice Item (child)**:

```
Item / Description
Qty / Rate / Amount
Expense Account    → কোন Expense Account-এ খরচ জমা হবে
Cost Center
```

# Chapter 4 : Purchase Invoice-এর GL Entry

Supplier-র থেকে $2,000 Laptop কেনা (VAT 15%), **Update Stock off** (Expense সরাসরি):

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Laptop/Office Equipment (Expense) | 2,000 | |
| Input VAT (Tax) | 300 | |
| Creditors (Payable) | | 2,300 |

> **Dr = Expense + Tax; Cr = Payable।**

---

# Chapter 5 : Purchase Receipt + Purchase Invoice (Perpetual Inventory)

Update Stock On থাকলে দুই ধাপে হয়:

**Step 1 : Purchase Receipt (মাল ঢুকল, Bill এখনো আসেনি)**

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Stock In Hand | 2,000 | |
| Stock Received But Not Billed | | 2,000 |

**Step 2 : Purchase Invoice (Bill এলো)**

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Stock Received But Not Billed | 2,000 | |
| Creditors | | 2,000 |

> **`Stock Received But Not Billed` একটা Bridge Account — মাল ঢুকেছে কিন্তু Bill আসেনি, সেই gap পূরণ করে।**

---

# Chapter 6 : Debit Note (কেনা ফেরত / কমানো)

Supplier-কে মাল ফেরত দিলে বা Bill কমালে — **Debit Note** (is_return = 1)।

```
Purchase Debit Note Submit:
Debit  Creditors          2,000
Credit Stock/Expense      2,000
```

> **Debit Note = Purchase Invoice-এর উল্টো। দেনা আর Expense/Stock কমে।**

# Interview Questions

1. **Purchase Invoice Submit করলে GL Entry কী?** — Dr Expense/Stock / Cr Creditors (+ Tax)।
2. **Stock Received But Not Billed কী?** — মাল ঢুকেছে, Bill আসেনি — Bridge Liability Account।
3. **Purchase Receipt আর Purchase Invoice-এর পার্থক্য?** — Receipt মাল ঢোকায় (Dr Stock), Invoice দেনা চেনে (Cr Creditors)।
4. **Debit Note কী?** — Purchase Invoice-এর উল্টো (ফেরত/কমানো)।
5. **Expense Account কোথায় দেওয়া হয়?** — Purchase Invoice Item-এ প্রতিটা Item-এর জন্য।

# Common Mistakes

❌ Expense Account ভুল দেওয়া (রান্নার খরচে Office Equipment)
❌ Purchase Receipt আর Invoice একই মনে করা
❌ Debit Note না করে Invoice Edit করা
❌ Tax Template না দিলে Input VAT আসে না
❌ Supplier না দিয়ে Payable Line রাখা

# Cheat Sheet

```
Supplier Order
        │
        ▼
Purchase Receipt → Dr Stock / Cr Stock Received But Not Billed
        │
        ▼
Purchase Invoice → Dr Stock Received But Not Billed / Cr Creditors
        │
        ▼
Payment Entry → Dr Creditors / Cr Bank
        │
        ▼
Outstanding = 0
```
