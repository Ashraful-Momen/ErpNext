# Module 2: Journal Entry — ERPNext Complete Note

আজ আমরা ERPNext Accounting-এর **Engine** শিখব।

> **Journal Entry বুঝলে ERPNext Accounting-এর ৮০% বুঝে যাবে। কারণ Sales Invoice, Purchase Invoice, Payment Entry — সব শেষ পর্যন্ত GL Entry-ই তৈরি করে, আর Manual Entry-র জন্য Journal Entry-ই হাতিয়ার।**

---

# Chapter 1 : Odoo vs ERPNext — এক গুরুত্বপূর্ণ পার্থক্য

Odoo-তে আলাদা "Journal" Master থাকে (Sales Journal, Purchase Journal, Bank Journal...)।

**ERPNext-এ আলাদা Journal Master নেই।** ERPNext-এ "Journal"-এর কাজ করে:

```
Voucher Type / Journal Entry Type
```

একটাই Document `Journal Entry` — কিন্তু তার `Voucher Type` বদলে ভিন্ন ভিন্ন কাজ হয়।

| Journal Entry Type | কাজ |
| ------------------ | --- |
| Journal Entry | সাধারণ Manual Entry |
| Bank Entry | Bank জড়িত Entry |
| Cash Entry | Cash জড়িত Entry |
| Contra Entry | Bank ↔ Cash Transfer |
| Opening Entry | বছরের Opening Balance |
| Depreciation Entry | Asset-এর অবচয় |
| Exchange Rate Revaluation | Currency Rate ঠিক করা |
| Inter Company Journal Entry | Multi-company লেনদেন |
| Debit Note / Credit Note | ফেরত/কমানো |
| Reversal Journal Entry | উল্টো Entry |

---

# Chapter 2 : Journal Entry কী?

প্রতিটা Financial Transaction-এর লিখিত Record, যেখানে **Debit = Credit** এবং কমপক্ষে **দুইটা Account** প্রভাবিত হয়।

---

# Chapter 3 : Debit / Credit Rule (DEA-LIC)

| Account | বাড়লে | কমলে |
| ------- | ------ | ----- |
| Asset | Debit | Credit |
| Expense | Debit | Credit |
| Liability | Credit | Debit |
| Equity | Credit | Debit |
| Income | Credit | Debit |

```
DEA বাড়লে Debit   →  Debit, Expense, Asset
LIC বাড়লে Credit  →  Liability, Income, Capital(Equity)
```

---

# Chapter 4 : Real Examples

## Example 1 : Owner Capital $10,000

```
Debit  Bank        $10,000  (Asset বাড়ল)
Credit Capital     $10,000  (Equity বাড়ল)
```

## Example 2 : Laptop $2,000 Cash-এ

```
Debit  Laptop      $2,000   (Asset বাড়ল)
Credit Cash        $2,000   (Asset কমল)
```

## Example 3 : বাকিতে Software বিক্রি $5,000

```
Debit  Receivable  $5,000   (Asset বাড়ল)
Credit Sales       $5,000   (Income বাড়ল)
```

## Example 4 : Salary $500

```
Debit  Salary Expense $500  (Expense বাড়ল)
Credit Bank          $500   (Asset কমল)
```

> **প্রতিবারই Debit Total = Credit Total — এটাই Double Entry।**

# Chapter 5 : Journal Entry-এর ভিতরে কী থাকে?

ERPNext-এ `Journal Entry` Document-এর Field:

```
Company
Posting Date
Voucher Type        → Journal Entry / Bank Entry / Cash Entry...
Entry Type          → ডকুমেন্টের নাম (Journal Entry, Payment Entry...)
Reference Number    → External reference
Accounts (child table) → Journal Entry Account
```

**Journal Entry Account (child)**-এর Field:

```
Account             → COA থেকে
Party Type / Party  → Customer / Supplier
Debit / Credit      → amount
Debit/Credit in Account Currency
Cost Center         → কোন Project/Dept
Against Account     → বিপরীত Account (Dr-Cr link)
```

> **মনে রাখো — একটা Journal Entry-তে অনেকগুলো Line (Account) থাকতে পারে, কিন্তু সব Line-এর Debit যোগফল = Credit যোগফল।**

---

# Chapter 6 : Difference Field (ERPNext-এর ম্যাজিক)

Journal Entry-তে একটা **Difference** Field থাকে। Odoo-র মতো:

```
Difference = Total Debit − Total Credit
```

> **Difference শূন্য না হলে ERPNext Save/Submit-ই করবে না।** এটাই Double-entry-র বাধ্যতামূলক Check।

---

# Chapter 7 : Multi Currency Journal Entry

ERPNext-এ এক Journal Entry-তে একাধিক Currency ব্যবহার করা যায়।

```
Multi Currency = Yes
Account Currency = USD
Exchange Rate = 110
Debit/Credit (base) = amount × rate
```

# Chapter 8 : Journal Entry-র Lifecycle

```
Draft      → লেখা হচ্ছে, GL Entry হয় না, Edit/Delete যায়
Submitted  → Final, GL Entry তৈরি হয়
Cancelled   → বাতিল, GL Entry reverse হয়
```

> **শুধু Submitted Document-ই GL Entry তৈরি করে — আর GL Entry-ই Report-এ যায়।**

# Chapter 9 : Database (Frappe DocType)

```
Journal Entry (tabJournal Entry)          → Header
Journal Entry Account (tabJournal Entry Account) → Lines (child)
GL Entry (tabGL Entry)                    → Submit-এর পর তৈরি হওয়া Ledger
```

Relationship:

```
Journal Entry → Journal Entry Account (child)
                    ↓ (submit করলে)
               GL Entry তৈরি হয়
                    ↓
               Report (Trial Balance, P&L...)
```

# Chapter 10 : Developer Perspective

```python
je = frappe.get_doc({
    "doctype": "Journal Entry",
    "company": "Ashraful Tech Ltd",
    "posting_date": "2026-07-01",
    "voucher_type": "Journal Entry",
    "accounts": [
        {"account": "Bank", "debit_in_account_currency": 10000},
        {"account": "Capital", "credit_in_account_currency": 10000},
    ],
})
je.insert()
je.submit()   # ← submit করলেই GL Entry তৈরি
```

> **ERPNext-এ `insert()` = Save (Draft), `submit()` = Post। Odoo-র `action_post()`-এর মতোই `submit()`।**

# Interview Questions

1. **Journal Entry কী?** — একটা Transaction-এর Double-entry Record (Debit = Credit)।
2. **Odoo-র Journal আর ERPNext-এর পার্থক্য?** — Odoo-তে আলাদা Journal Master; ERPNext-এ Voucher Type-ই Journal-এর কাজ করে।
3. **Difference Field কী?** — Debit Total − Credit Total; শূন্য না হলে Submit হয় না।
4. **Bank Entry আর Cash Entry কখন?** — Transaction-এ Bank/Cash Account জড়িত থাকলে।
5. **Contra Entry কী?** — Bank ↔ Cash নিজের টাকা Transfer।
6. **Draft আর Submitted-এর পার্থক্য?** — Draft GL Entry বানায় না; Submitted-ই GL Entry তৈরি করে Report-এ যায়।

---

# Common Mistakes

❌ Debit মানে "টাকা আসা" মনে করা
❌ Difference শূন্য না করেই Submit চেষ্টা করা
❌ Group Account-এ Entry দেওয়া
❌ Receivable/Payable Line-এ Party না দেওয়া
❌ ভুল Posting Date — Report-এর Period গুলিয়ে যায়
❌ Draft অবস্থায় Report না মেলার কারণ খোঁজা
