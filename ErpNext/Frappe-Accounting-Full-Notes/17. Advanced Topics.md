# Advanced Topics — ERPNext Accounting (Extra)

এখানে ERPNext Accounting-এর কিছু **Advanced কিন্তু গুরুত্বপূর্ণ** বিষয় — Cost Center, Budget, Deferred Revenue/Expense, Multi-currency, Exchange Rate Revaluation, Payment Terms, Auto-Repeat।

---

# Topic 1 : Cost Center

**Cost Center** = Company-র ভিতরে আলাদা Department/Project/Unit — যাতে খরচ আর আয় বিভাগ অনুযায়ী আলাদা হয়।

```
Cost Center (tabCost Center)
├── Marketing
├── Development
└── Support
```

প্রতিটা Journal Entry / Sales / Purchase Line-এ Cost Center দেওয়া যায়।

> **Report-এ Cost Center Filter দিয়ে "Marketing-এ কত খরচ হয়েছে" বের হয়।**

---

# Topic 2 : Budget

**Budget** = আগে থেকে ঠিক করা খরচের সীমা। খরচ Budget ছাড়িয়ে গেলে সতর্ক করে।

```
Budget (tabBudget)
├── Fiscal Year
├── Account
└── Budget Amount (মাসিক/বার্ষিক)
```

> **Purchase Invoice / Expense Entry-তে Budget limit থাকলে Warning দেয়।**

---

# Topic 3 : Deferred Revenue / Deferred Expense

আগে টাকা নিলে কিন্তু Service পরে দিলে — Revenue-টা পরে চেনা হয়। এটা **Deferred Revenue**।

```
আজ $12,000 নিলাম (১ বছরের Subscription)
প্রতি মাসে Revenue চেনা হবে $1,000
```

GL Entry:

```
Payment:   Dr Bank / Cr Deferred Revenue (Liability)
প্রতি মাসে: Dr Deferred Revenue 1,000 / Cr Sales 1,000
```

> **Voucher Type `Deferred Revenue` / `Deferred Expense` Journal Entry ব্যবহার হয়।**

---

# Topic 4 : Multi-currency

একাধিক Currency-তে লেনদেন — USD, EUR, BDT।

```
Account Currency = USD
Exchange Rate    = 110
Base Currency    = BDT
```

> **ERPNext-এ প্রতিটা Account-এর Currency থাকতে পারে, আর Exchange Rate-এ Base Currency-তে Convert হয়।**

---

# Topic 5 : Exchange Rate Revaluation

Currency-র Rate বদলালে — বিদেশি Account-এর Balance আবার ঠিক করা হয়।

```
Journal Entry → Voucher Type = Exchange Rate Revaluation
```

> **Unrealized Gain/Loss ধরে — `Exchange Gain/Loss` Account-এ বসে।**

---

# Topic 6 : Payment Terms

Invoice-তে কবে টাকা দিতে হবে — শর্ত।

```
Payment Terms:
├── 50% Advance
├── 30% on Delivery
└── 20% 30 দিনে
```

> **Payment Terms দিলে Due Date, Payment Schedule তৈরি হয়।**

---

# Topic 7 : Auto-Repeat

প্রতি মাসে একই Invoice/Entry Auto তৈরি করা (Subscription)।

```
Auto Repeat (tabAuto Repeat)
├── Reference Document (Sales Invoice)
├── Frequency (Monthly)
└── End Date
```

> **Subscription Business-এ Auto-Repeat দিয়ে প্রতিমাসে Invoice Auto হয়।**

---

# Topic 8 : Round Off

Amount-এ ছোট ভগ্নাংশ (.01) হলে — Round Off Account দিয়ে মিলানো হয়।

```
Grand Total $1,000.005 → Round Off $0.005
Account Type = Round Off
```

---

# Cheat Sheet

```
Cost Center      → Department-ভিত্তিক খরচ/আয়
Budget           → খরচের সীমা
Deferred         → পরে Revenue/Expense চেনা
Multi-currency   → একাধিক Currency
Revaluation      → Rate বদলে Balance ঠিক
Payment Terms    → কবে টাকা
Auto-Repeat      → Auto Invoice
Round Off        → ভগ্নাংশ মিলানো
```

# Interview Questions

1. **Cost Center কেন?** — Department/Project অনুযায়ী খরচ আলাদা করতে।
2. **Deferred Revenue কী?** — আগে টাকা নেওয়া, পরে Revenue চেনা।
3. **Exchange Rate Revaluation কখন?** — Currency Rate বদলালে বিদেশি Balance ঠিক করতে।
4. **Auto-Repeat কী?** — নির্দিষ্ট সময় পর Auto Document তৈরি।
5. **Budget-এর কাজ?** — খরচের সীমা সতর্ক করা।
