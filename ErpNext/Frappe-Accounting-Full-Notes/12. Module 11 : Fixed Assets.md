# Module 11: Fixed Assets — ERPNext Complete Note

আজ শিখব **Fixed Asset (Laptop, Vehicle, Building)** — কেনা থেকে শুরু করে **Depreciation (অবচয়)** পর্যন্ত।

> **Odoo-র account.asset-এর ERPNext সংস্করণ: Asset DocType + Depreciation Schedule + Depreciation Entry।**

---

# Chapter 1 : Fixed Asset কী?

দীর্ঘদিন ব্যবহার হবে এমন সম্পদ — Laptop, Vehicle, Building, Machine।

```
Account: Laptop (Account Type = Fixed Asset, Root Type = Asset)
```

> **Stock-এর মতো বিক্রির জন্য না, ব্যবহারের জন্য। তাই আলাদা Account Type।**

---

# Chapter 2 : Asset DocType-এর ভিতরে

`Asset` DocType:

```
Asset Name          → "Dell Laptop #1"
Item Code           → (link with Item, optional)
Gross Purchase Amount → 80,000
Purchase Date
Asset Category      → Electronics / Furniture / Vehicle
Is Existing Asset   → আগে থেকে আছে কিনা
Location
Depreciation Method → Straight Line / Double Declining Balance / Written Down Value
Frequency           → Monthly / Yearly
Total Number of Depreciations → 36 (মাস)
```

> **Asset Category দিয়ে Default Account আর Depreciation Method সেট হয়।**

---

# Chapter 3 : Depreciation (অবচয়) কী?

Fixed Asset-এর মূল্য সময়ের সাথে কমে যায় — এই কমাকে **Depreciation** বলে। এটা একটা Expense।

```
Asset $36,000, Life 3 বছর (36 মাস), Straight Line:
প্রতি মাসের Depreciation = 36,000 / 36 = $1,000
```

---

# Chapter 4 : Depreciation Method

| Method | নিয়ম |
| ------ | ----- |
| **Straight Line** | প্রতি মাসে সমান Amount |
| **Double Declining Balance** | শুরুতে বেশি, পরে কম |
| **Written Down Value** | বাকি Value-র উপর % |

> **সবচেয়ে সাধারণ: Straight Line।**

---

# Chapter 5 : Depreciation-এর GL Entry

প্রতি মাসে Depreciation Entry (Voucher Type = `Depreciation Entry`):

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Depreciation Expense | 1,000 | |
| Accumulated Depreciation | | 1,000 |

> **`Accumulated Depreciation` = Contra-Asset। এটা Credit-এ বাড়ে, আর Asset-এর Net Value কমায়।**

---

# Chapter 6 : Asset-এর Net Value

```
Asset (Gross)           = 36,000
Accumulated Depreciation = -3,000  (৩ মাস পরে)
─────────────────────────────────
Net Book Value          = 33,000
```

> **Balance Sheet-এ দেখায়: Laptop $36,000 − Accumulated Depreciation $3,000 = $33,000।**

# Chapter 7 : Asset কেনা থেকে Depreciation-এর পুরো Flow

```
১. Purchase Invoice / Purchase Receipt (Is Fixed Asset Item)
        │
        ▼
২. Asset Document তৈরি হয় (Gross Amount, Category)
        │
        ▼
৩. Depreciation Schedule তৈরি হয় (প্রতি মাসের Amount)
        │
        ▼
৪. প্রতি মাসে Depreciation Entry (Auto/Manual)
        │
        ▼
৫. GL Entry: Dr Depreciation / Cr Accumulated Depreciation
```

# Interview Questions

1. **Depreciation কী?** — Fixed Asset-এর মূল্য সময়ের সাথে কমে যাওয়া (Expense)।
2. **Accumulated Depreciation কোন Type?** — Contra-Asset (Credit-এ বাড়ে)।
3. **Straight Line Method কী?** — প্রতি মাসে সমান Amount (Cost / Life)।
4. **Depreciation Entry-এর GL Entry কী?** — Dr Depreciation Expense / Cr Accumulated Depreciation।
5. **Net Book Value কীভাবে বের হয়?** — Gross Asset − Accumulated Depreciation।

---

# Common Mistakes

❌ Accumulated Depreciation-কে Normal Asset ভাবা
❌ Straight Line-এ ভুল Total Number
❌ Depreciation Entry না দিলে Asset-এর Value পুরোই দেখায়
❌ Asset আর Stock (Inventory) গুলিয়ে ফেলা
❌ Asset Movement না করে Location Edit করা

---

# Cheat Sheet

```
Asset কেনা → Purchase Invoice (Is Fixed Asset)
        │
        ▼
Asset Doc + Depreciation Schedule
        │
        ▼
প্রতি মাসে: Dr Depreciation / Cr Accumulated Depreciation
        │
        ▼
Balance Sheet: Gross − Accumulated = Net
```
