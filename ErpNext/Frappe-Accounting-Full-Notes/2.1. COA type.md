# ERPNext Account Type & Root Type — সম্পূর্ণ Reference

ERPNext-এ Account-এর দুইটা Type Field আছে: **Root Type** (broad, ৫টা) আর **Account Type** (specific)। এই দুটো সঠিকভাবে দিলেই Report আর Document Flow সঠিক হবে।

---

## ১. Root Type (৫টা — Balance Sheet নাকি P&L ঠিক করে)

| Root Type | বাংলা অর্থ | Report |
| --------- | ---------- | ------ |
| Asset     | যা আছে    | Balance Sheet |
| Liability | যা দিতে হবে | Balance Sheet |
| Equity    | মালিকের   | Balance Sheet |
| Income    | আয়        | Profit & Loss |
| Expense   | খরচ       | Profit & Loss |

> Asset, Liability, Equity-এর Balance বছরে বছরে বয়ে যায় (Permanent)।
> Income, Expense বছরের শেষে Retained Earnings-এ যায় (Temporary)।

---

## ২. Account Type (Specific — Document Behavior ঠিক করে)

| Account Type | Root Type | কী / কোথায় ব্যবহার হয় |
| ------------ | --------- | ----------------------- |
| Bank | Asset | Bank Account — Payment Entry, Bank Entry |
| Cash | Asset | নগদ — Payment Entry (Cash Mode) |
| Receivable | Asset | Customer-এর কাছে পাওনা — Sales Invoice |
| Payable | Liability | Vendor-কে দেনা — Purchase Invoice |
| Stock | Asset | গুদামের মাল — Purchase Receipt, Delivery Note |
| Stock Received But Not Billed | Liability | মাল এসেছে, Bill আসেনি (bridge) |
| Stock Adjustment | Expense | Stock Entry / Reconciliation |
| Fixed Asset | Asset | Laptop, Vehicle, Building |
| Accumulated Depreciation | Contra-Asset | Asset-এর কমে যাওয়া মূল্য |
| Depreciation | Expense | প্রতি মাসের অবচয় |
| Cost of Goods Sold | Expense | বিক্রি হওয়া মালের দাম |
| Tax | Liability/Asset | VAT, Sales/Purchase Tax |
| Expense Account | Expense | সাধারণ খরচ |
| Income Account | Income | আয় |
| Equity | Equity | Capital, Retained Earnings |
| Round Off | Expense | হিসাবের গোলযোগ (.01) |
| Temporary | — | Period Closing-এর সময় |
| Chargeable | Expense | Billable খরচ |
| Expenses Included In Valuation | Expense | Landed cost-এর জন্য |
| Asset Received But Not Billed | Liability | Asset এসেছে, Bill আসেনি |
| Capital Work in Progress | Asset | নির্মাণাধীন সম্পদ |

## ৩. ERPNext Default COA-র গঠন (Standard Chart)

```
Assets (Application of Funds)
├── Current Assets
│    ├── Cash (1110)
│    ├── Bank (1210)
│    ├── Accounts Receivable / Debtors (1310)
│    └── Stock In Hand (1410)
└── Fixed Assets
     └── ... (Accumulated Depreciation সহ)

Liabilities (Sources of Funds)
├── Current Liabilities
│    ├── Accounts Payable / Creditors (2110)
│    └── Tax / VAT Payable
└── ...

Equity
├── Capital / Share Capital
└── Retained Earnings

Income
└── Sales / Service Income

Expenses
├── Cost of Goods Sold
├── Salary, Rent, Utilities...
```

> দেশ/লোকালাইজেশন অনুযায়ী নাম বদলায় (Debtors/Creditors vs Accounts Receivable/Payable), কিন্তু Root Type আর Account Type একই থাকে।

---

## ৪. Golden Rules (ভুল না করার জন্য)

1. **Customer-এর পাওনা** → Account Type = `Receivable` (Root: Asset)।
2. **Vendor-এর দেনা** → Account Type = `Payable` (Root: Liability)।
3. **Bank/Cash** → Account Type = `Bank` / `Cash` (Root: Asset)।
4. **গুদামের মাল** → Account Type = `Stock` (Root: Asset)।
5. **বিক্রি হওয়া মালের দাম** → Account Type = `Cost of Goods Sold` (Root: Expense)।
6. **Fixed Asset-এর মূল্য কমা** → `Accumulated Depreciation` (Contra-Asset, Credit-এ বাড়ে)।

> **Contra-Asset (Accumulated Depreciation) লিক নিয়মে চলে** — বাড়লে Credit, কমলে Debit। Normal Asset-এর উল্টো।

---

## ৫. Company-তে Default Accounts

ERPNext-এ Company Master-এ Default Account Set করা থাকে, যাতে Odoo-র মতো প্রায়ই Account select করতে না হয়:

```
default_receivable_account   → Debtors
default_payable_account      → Creditors
default_cash_account         → Cash
default_bank_account         → Bank
default_income_account       → Sales
default_expense_account      → Expense
default_currency             → BDT
```

> Default Account ঠিক থাকলে Sales/Purchase Invoice, Payment Entry — সব নিজে নিজে সঠিক Account নেয়।
