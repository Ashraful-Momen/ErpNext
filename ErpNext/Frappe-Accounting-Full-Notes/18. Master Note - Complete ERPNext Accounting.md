# Master Note — Complete ERPNext Accounting (Condensed)

এটাই ERPNext Accounting-এর **সম্পূর্ণ সারসংক্ষেপ**। সব Module এক জায়গায়।

---

## ১. Foundation

```
Business → Owner Invest → Asset → Loan = Liability → Owner-এর অংশ = Equity
Sales → Revenue | খরচ → Expense
Profit = Revenue − Expense
সব সময়: Assets = Liabilities + Equity
```

---

## ২. Debit / Credit (DEA-LIC)

```
DEA বাড়লে Debit  → Debit(Asset), Expense, Asset
LIC বাড়লে Credit → Liability, Income, Capital(Equity)
```

| Account | বাড়লে | কমলে |
| ------- | ------ | ----- |
| Asset | Dr | Cr |
| Expense | Dr | Cr |
| Liability | Cr | Dr |
| Equity | Cr | Dr |
| Income | Cr | Dr |

---

## ৩. COA (Chart of Accounts)

```
Account → Root Type (5টা) + Account Type + Is Group/Ledger + Company
```

- Root Type: Asset, Liability, Equity, Income, Expense
- Group Account → Entry হয় না; Ledger Account → Entry হয়
- Account Type: Bank, Cash, Receivable, Payable, Stock, Fixed Asset, Tax, COGS...

---

## ৪. GL Entry (Single Ledger) — হৃদয়

```
Sales Invoice ─┐
Purchase Invoice ─┤
Payment Entry ──┼──► GL Entry (tabGL Entry) ◄── একটাই Ledger
Journal Entry ──┤
Delivery Note ──┘
```

- Draft → GL Entry নেই; Submitted → GL Entry; Cancelled → reverse (is_cancelled = 1)
- সব Report GL Entry থেকে আসে

---

## ৫. Journal Entry

```
Document: Journal Entry (Voucher Type = Journal Entry Type)
Difference = Total Dr − Total Cr = 0 (বাধ্যতামূলক)
```

Voucher Types: Journal Entry, Bank Entry, Cash Entry, Contra Entry, Opening Entry, Depreciation Entry, Exchange Rate Revaluation, Inter Company, Deferred Revenue/Expense, Reversal।

---

## ৬. Payment Entry

```
Receive → Dr Bank / Cr Receivable
Pay     → Dr Payable / Cr Bank
Internal Transfer → Dr Bank / Cr Cash
```

References Table → Invoice-এর Outstanding কমায়। Advance → is_advance = 1।

---

## ৭. Bank & Reconciliation

```
Bank Statement ↔ GL Entry (Payment) Match
Unmatched → Journal Entry (Bank Charge, Interest)
```

---

## ৮. Customer (Sales Invoice)

```
Sales Invoice → Dr Debtors / Cr Sales (+ VAT)
Update Stock → + Dr COGS / Cr Stock
Credit Note → উল্টো (is_return = 1)
```

---

## ৯. Vendor (Purchase Invoice)

```
Purchase Receipt → Dr Stock / Cr Stock Received But Not Billed
Purchase Invoice → Dr SRBNB / Cr Creditors
Debit Note → উল্টো (is_return = 1)
```

---

## ১০. Taxes

```
Output VAT (Sales) − Input VAT (Purchase) = VAT Payable
Tax Withholding (TDS) → Payment থেকে কাটা
```

---

## ১১. Inventory Accounting

```
Purchase Receipt → Dr Stock / Cr SRBNB
Delivery Note    → Dr COGS / Cr Stock   ← COGS Delivery-তে!
Sales Invoice    → Dr Debtors / Cr Sales + VAT
```

Valuation: FIFO / Moving Average। Stock Ledger Entry = Quantity+Value।

---

## ১২. Fixed Assets

```
Asset → Depreciation Schedule → প্রতি মাসে:
Dr Depreciation Expense / Cr Accumulated Depreciation
Net Book Value = Gross − Accumulated Depreciation
```

---

## ১৩. Reports

```
Trial Balance (Dr=Cr) | General Ledger | P&L (Income−Expense)
Balance Sheet (Assets=Liab+Equity) | AR/AP (Party Balance)
— সব GL Entry থেকে
```

---

## ১৪. Fiscal Year & Period Closing

```
Fiscal Year (Start↔End) → Period Closing Voucher
→ Income/Expense → P&L → Retained Earnings
```

---

## ১৫. Multi Company & Inter Company

```
প্রতিটা Document-এ `company` field
Inter Company Journal Entry → দুই Company-র Entry এক Document-এ
```

## সবচেয়ে গুরুত্বপূর্ণ ৫টা কথা

1. **ERPNext = Document + GL Entry (Single Ledger)।**
2. **শুধু Submitted Document-ই GL Entry বানায়, Report-এ আসে।**
3. **COGS Delivery Note-এ চেনে (Invoice-এ নয়) — Odoo-র সাথে বড় পার্থক্য।**
4. **সব Report `tabGL Entry` থেকে — আলাদা Table নয়।**
5. **Developer-এর Golden Filter: `is_cancelled = 0`, `company`, `posting_date`।**
