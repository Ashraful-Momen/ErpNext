# Master Note — Definitions & Use Cases (ERPNext Accounting)

প্রতিটা গুরুত্বপূর্ণ Term-এর **সংজ্ঞা + বাস্তব Use Case** — Interview আর বাস্তব কাজের জন্য।

---

## Core Terms

| Term | Definition | Use Case |
| ---- | ---------- | -------- |
| **GL Entry** | Single Ledger; প্রতিটা Accounting Document Submit-এ তৈরি হওয়া Record (Dr/Cr)। | Sales Invoice Submit → Dr Debtors / Cr Sales। সব Report-এর উৎস। |
| **Account** | COA-র প্রতিটা Entry; Root Type + Account Type থাকে। | Bank, Cash, Sales, Salary — প্রতিটা একটা Account। |
| **Root Type** | ৫টা broad category: Asset, Liability, Equity, Income, Expense। | ঠিক করে Account Balance Sheet-এ নাকি P&L-এ। |
| **Account Type** | Specific nature: Bank, Cash, Receivable, Payable, Stock, Tax... | ঠিক করে কোন Document-এ Account select হবে। |
| **Is Group / Ledger** | Group = parent (Entry হয় না); Ledger = final (Entry হয়)। | "Current Assets" Group-এর ভিতরে "Bank" Ledger। |
| **Journal Entry** | Manual Double-entry Document (Dr = Cr)। | Accrual, Prepaid, Opening, Adjustment। |
| **Voucher Type** | Journal Entry-র প্রকার: Bank Entry, Contra Entry, Opening Entry... | Cash→Bank Transfer-এ "Contra Entry"। |
| **Payment Entry** | টাকা দেওয়া-নেওয়ার Document (Receive/Pay/Internal Transfer)। | Customer Payment Receive, Vendor Payment Pay। |
| **Sales Invoice** | Customer-কে বিক্রির Bill; Revenue তৈরি করে। | Software বিক্রি → Dr Debtors / Cr Sales। |
| **Purchase Invoice** | Supplier-এর কাছ থেকে কেনার Bill; Expense তৈরি করে। | Laptop কেনা → Dr Expense / Cr Creditors। |
| **Credit Note** | Sales Invoice-এর উল্টো (is_return = 1)। | Customer মাল ফেরত দিলে Revenue কমায়। |
| **Debit Note** | Purchase Invoice-এর উল্টো (is_return = 1)। | Supplier-কে মাল ফেরত দিলে দেনা কমায়। |
| **Stock Ledger Entry** | Inventory-র Quantity + Value রেকর্ড। | Delivery Note-এ মাল বের → Stock কমে। |
| **COGS** | বিক্রি হওয়া মালের দাম (Cost of Goods Sold)। | Delivery Note → Dr COGS / Cr Stock। |
| **Stock Received But Not Billed** | মাল ঢুকেছে, Bill আসেনি — Bridge Liability। | Purchase Receipt-এর বিপরীতে Credit। |
| **Depreciation** | Fixed Asset-এর মূল্য সময়ের সাথে কমা (Expense)। | প্রতি মাসে Dr Depreciation / Cr Accumulated Depreciation। |
| **Accumulated Depreciation** | Asset-এর মোট কমে যাওয়া মূল্য (Contra-Asset)। | Balance Sheet-এ Asset থেকে বাদ। |
| **Trial Balance** | প্রতিটা Account-এর Dr/Cr Balance-এর Summary। | Dr = Cr check করে ভুল ধরা। |
| **P&L Statement** | Income − Expense = Profit/Loss। | মাসের Profit কত বের করা। |
| **Balance Sheet** | Assets = Liabilities + Equity। | নির্দিষ্ট দিনে আর্থিক অবস্থা। |
| **Fiscal Year** | ১২ মাসের আর্থিক সময়কাল। | 01 Jan – 31 Dec। Report-এর Period। |
| **Period Closing Voucher** | বছরের শেষে Income/Expense বন্ধ করে P&L → Retained Earnings। | ৩১ ডিসেম্বর বছরের হিসাব বন্ধ। |
| **Cost Center** | Department/Project-ভিত্তিক আলাদা হিসাব। | Marketing-এ কত খরচ বের করা। |
| **Budget** | আগে থেকে ঠিক করা খরচের সীমা। | খরচ Budget ছাড়ালে Warning। |
| **Deferred Revenue** | আগে টাকা নেওয়া, পরে Revenue চেনা। | ১ বছরের Subscription আগে নেওয়া। |
| **Tax Withholding** | Payment থেকে TDS কেটে সরকারে জমা। | Supplier Payment-এ 5% TDS কাটা। |
| **Company (Multi)** | আলাদা Legal Entity, আলাদা COA/Fiscal Year। | এক ERPNext-এ ৩টা কোম্পানি। |
| **Inter Company Journal Entry** | দুই Company-র Entry এক Document-এ। | Company A থেকে B-তে বিক্রি। |
| **DocType** | Frappe-র Database Table Schema। | Account DocType = tabAccount Table। |
| **hooks.py** | App-এর event/scheduler Configuration। | Sales Invoice on_submit-এ Notification। |

## Golden Use Cases

1. **মাস শেষে খরচ Accrue** → Journal Entry: Dr Expense / Cr Payable।
2. **রেন্ট Prepaid** → Journal Entry: Dr Prepaid / Cr Bank।
3. **বছরের Opening** → Journal Entry (Opening Entry): Dr Asset / Cr Equity।
4. **Customer Payment** → Payment Entry (Receive): Dr Bank / Cr Debtors।
5. **মাল ঢোকা, Bill নেই** → Purchase Receipt: Dr Stock / Cr SRBNB।
6. **মাল বিক্রি, Delivery** → Delivery Note: Dr COGS / Cr Stock।
7. **বিক্রির Bill** → Sales Invoice: Dr Debtors / Cr Sales + VAT।
8. **VAT জমা** → Journal Entry: Dr VAT Payable / Cr Bank।
9. **বছর শেষ** → Period Closing Voucher: Income/Expense → Retained Earnings।
10. **Developer-এ Balance Query** → `frappe.db.sql("SELECT SUM(debit-credit) FROM tabGL Entry WHERE is_cancelled=0")`।
