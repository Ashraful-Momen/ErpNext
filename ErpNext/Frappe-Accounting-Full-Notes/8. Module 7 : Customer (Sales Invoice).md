# Module 7: Customer & Sales Invoice — ERPNext Complete Note

আজ শিখব **Customer-কে বিক্রি** — Sales Invoice, Credit Note, আর এর GL Entry।

> **Odoo-র Customer Invoice-এর ERPNext সংস্করণ `Sales Invoice`। Submit করলে GL Entry: Dr Debtors / Cr Sales (+ Tax)।**

---

# Chapter 1 : Customer (Party) কী?

`Customer` DocType = যার কাছে তুমি বিক্রি করো।

```
Customer (tabCustomer)
├── Customer Name
├── Customer Group
├── Territory
├── Credit Limit
└── Default Currency / Payment Terms
```

> **Customer-এর পাওনা Accounts Receivable (Debtors) Account-এ জমা হয়।**

---

# Chapter 2 : Sales Invoice কী?

Customer-কে বিক্রির Bill/Document। এটাই Revenue তৈরি করে।

```
Sales Invoice (tabSales Invoice)
├── Customer
├── Posting Date / Due Date
├── Items (child: Sales Invoice Item)
├── Taxes and Charges
├── Update Stock (checkbox)
└── Payment Terms
```

**Sales Invoice Item (child)**:

```
Item / Description
Qty / Rate / Amount
Income Account     → কোন Income Account-এ বিক্রি জমা হবে
Cost Center
```

# Chapter 3 : Sales Flow (Standard)

```
Quotation
   │
   ▼
Sales Order
   │
   ▼
Delivery Note   (মাল গুদাম থেকে বের হয়)
   │
   ▼
Sales Invoice   (Bill হয়, Revenue চেনে)
   │
   ▼
Payment Entry   (টাকা আসে)
```

> ছোট ব্যবসায় সরাসরি Sales Invoice-ও করা যায়।

# Chapter 4 : Sales Invoice-এর GL Entry

Customer-কে $5,000 Software বিক্রি (VAT 15%), **Update Stock off**:

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Debtors (Receivable) | 5,750 | |
| Sales | | 5,000 |
| VAT Payable | | 750 |

> **Sales Invoice Submit = ৩টা GL Entry। মোট Dr = মোট Cr = 5,750।**

---

# Chapter 5 : Update Stock ON করলে কী হয়?

`Update Stock = Yes` থাকলে Sales Invoice-ই Delivery-এর কাজ করে — COGS Entry যোগ হয়:

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Debtors | 5,750 | |
| Sales | | 5,000 |
| VAT Payable | | 750 |
| Cost of Goods Sold | 3,000 | |
| Stock In Hand | | 3,000 |

> **COGS = বিক্রি হওয়া মালের দাম। মালের Cost-এ Stock কমে, COGS Expense-এ বসে।**

---

# Chapter 6 : Credit Note (বিক্রি ফেরত / কমানো)

Customer মাল ফেরত দিলে বা Bill কমালে — **Credit Note** (is_return = 1)।

```
Sales Credit Note Submit:
Debit  Sales              5,000
Credit Debtors            5,000
```

> **Credit Note = Sales Invoice-এর উল্টো। Revenue আর Debtors কমে।**

---

# Chapter 7 : Outstanding & Payment

```
Sales Invoice $5,750 → Outstanding = $5,750
Payment Entry $5,750 → Outstanding = $0
```

> **Payment Entry-র References-এ Sales Invoice ধরা থাকলে Outstanding কমে।**

# Interview Questions

1. **Sales Invoice Submit করলে GL Entry কী?** — Dr Debtors / Cr Sales (+ Tax)।
2. **Update Stock On করলে কী বাড়তি Entry?** — Dr COGS / Cr Stock।
3. **Credit Note কী?** — Sales Invoice-এর উল্টো (ফেরত/কমানো)।
4. **Outstanding কীভাবে কমে?** — Payment Entry-র References-এ Invoice লিংক করলে।
5. **Delivery Note আর Sales Invoice-এর পার্থক্য?** — Delivery Note মাল বের করে (COGS), Sales Invoice Revenue চেনে।

# Common Mistakes

❌ Income Account ভুল দেওয়া (Sales-এর বদলে অন্য Account)
❌ Update Stock চেক না করলে COGS Entry হয় না
❌ Credit Note না করে Invoice Edit করা
❌ Party না দিয়ে Receivable Line রাখা
❌ Tax Template না দিলে VAT আসে না

# Cheat Sheet

```
Customer Order
        │
        ▼
Sales Invoice (Items + Tax)
        │
        ▼
Submit → Dr Debtors / Cr Sales (+VAT)
        │          (Update Stock: + Dr COGS / Cr Stock)
        ▼
Payment Entry → Dr Bank / Cr Debtors
        │
        ▼
Outstanding = 0
```
