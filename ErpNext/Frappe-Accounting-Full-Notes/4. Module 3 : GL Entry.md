# Module 3: GL Entry (Single Ledger) — ERPNext-এর হৃদয়

এটাই ERPNext Accounting-এর **সবচেয়ে গুরুত্বপূর্ণ Module**।

> **ERPNext-এ সব Accounting-এর একটাই টেবিল — `GL Entry` (tabGL Entry)। Sales Invoice হোক, Payment Entry হোক, Journal Entry হোক — সব Submit হলেই এখানে এসে মেশে। এটাই Odoo-র `account.move.line`-এর ERPNext সংস্করণ, কিন্তু আরও সুন্দরভাবে Single।**

---

# Chapter 1 : Real Life Story

ভাবো একটা বড় কোম্পানির Accounts Department। সব Department (Sales, Purchase, Cash) নিজের কাজ করে, কিন্তু সবাই শেষে Accounts-এ এসে একটা **মূল খাতা (General Ledger)**-তে লেখে।

```
Sales Department ─┐
Purchase Dept ────┼──► General Ledger (একটাই খাতা)
Cash/Bank Dept ───┘
```

ERPNext-এ এই "মূল খাতা"-ই হলো **GL Entry**।

---

# Chapter 2 : Single Ledger Concept

```
Sales Invoice      ─┐
Purchase Invoice   ─┤
Payment Entry      ─┼──►  GL Entry (tabGL Entry)  ◄── একটাই Ledger
Journal Entry      ─┤
Delivery Note      ─┘
```

> **প্রতিটা Accounting Document Submit করলেই নিজে নিজে GL Entry তৈরি করে।**

Odoo-তে Invoice/Bill/Payment সবই `account.move` (একটাই Table, শুধু move_type আলাদা)।

ERPNext-এ ব্যাপারটা ভিন্ন — Document-গুলো আলাদা আলাদা (Sales Invoice, Purchase Invoice, Payment Entry), কিন্তু **সবাই GL Entry-তে Post করে**।

```
Odoo   : Document = account.move (একটাই)
ERPNext: Document আলাদা, কিন্তু Post সবাই GL Entry-তে
```

# Chapter 3 : GL Entry-এর ভিতরে কী থাকে?

`GL Entry` DocType-এর গুরুত্বপূর্ণ Field:

```
posting_date        → কোন দিনের লেনদেন
account             → COA-র কোন Account
debit / credit      → base currency-তে Dr/Cr
debit_in_account_currency / credit_in_account_currency
against             → বিপরীত Account (Dr-Cr link)
against_voucher     → বিপরীত Document
voucher_no          → কোন Document থেকে (SI-0001, JV-0001...)
voucher_type        → Sales Invoice / Journal Entry / Payment Entry...
party_type / party  → Customer / Supplier
cost_center         → Project / Dept
project
is_opening          → Opening Entry কিনা
is_advance          → Advance Payment কিনা
is_cancelled        → Cancel হয়েছে কিনা
company
fiscal_year
```

# Chapter 4 : একটা Sales Invoice-এ GL Entry-তে কী হয়?

Customer-কে $5,000 Software বিক্রি (VAT 15%)।

Sales Invoice Submit করলে **GL Entry-তে ৩টা Row**:

| Account | Debit | Credit | Voucher |
| ------- | ----- | ------ | ------- |
| Accounts Receivable | 5,750 | | Sales Invoice |
| Sales | | 5,000 | Sales Invoice |
| VAT Payable | | 750 | Sales Invoice |

> **একটা Document Submit = এক বা একাধিক GL Entry Row। সব Row-এর মোট Debit = মোট Credit।**

# Chapter 5 : Draft vs Submitted

```
Draft     → GL Entry তৈরি হয় না, Report-এ আসে না
Submitted → GL Entry তৈরি হয়, Report-এ আসে
Cancelled → GL Entry reverse (is_cancelled = 1)
```

> **মনে রাখো — Report সবসময় Submitted Document-এর GL Entry থেকে আসে। Draft কোনো Report-এ নেই।**

Odoo-র "শুধু Posted Entry-ই Report-এ যায়" — ERPNext-এ তার বদলে "শুধু Submitted Document-এর GL Entry-ই Report-এ যায়"।

---

# Chapter 6 : Cancel করলে কী হয়?

Document Cancel করলে ERPNext দুইটা কাজ করতে পারে:

```
১. GL Entry-গুলো Delete করে দেয়
২. বা GL Entry-গুলো is_cancelled = 1 করে reverse
```

> পুরনো Period-এর Document Cancel করলে সাধারণত **Reverse Entry** হয়, যাতে Audit Trail অক্ষুণ্ণ থাকে।

# Chapter 7 : Report-গুলো GL Entry থেকে

```
Trial Balance  → GL Entry-র Account-ভিত্তিক Debit/Credit Sum
P&L            → Income − Expense (GL Entry থেকে)
Balance Sheet  → Asset = Liability + Equity
General Ledger → প্রতিটা Account-র প্রতিটা GL Entry
```

> **একটাই উৎস — `tabGL Entry`। Report আলাদা Table না, শুধু Query।**

# Chapter 8 : Database (Frappe DocType)

# Chapter 9 : Developer Perspective

GL Entry Query করা (Frappe):

```python
# কোনো Account-এর Balance
gl = frappe.db.sql("""
    SELECT SUM(debit) - SUM(credit) AS balance
    FROM `tabGL Entry`
    WHERE account = %s AND company = %s AND is_cancelled = 0
""", ("Bank", "Ashraful Tech Ltd"))
```

```python
# কোনো Customer-এর মোট পাওনা
frappe.db.sql("""
    SELECT SUM(debit) - SUM(credit)
    FROM `tabGL Entry`
    WHERE account = 'Debtors' AND party_type = 'Customer'
      AND party = %s AND is_cancelled = 0
""", customer_name)
```

> **Developer-এর ৩টা Filter কখনো ভুলবে না: `is_cancelled = 0`, `company`, `posting_date`।**

# Interview Questions

1. **GL Entry কী?** — ERPNext-এর Single Ledger; প্রতিটা Accounting Document Submit করলে যে Record তৈরি হয়।
2. **Odoo-র account.move আর ERPNext-এর GL Entry-র পার্থক্য?** — Odoo-তে document-ই move; ERPNext-এ document আলাদা, GL Entry হলো Post-করা Ledger।
3. **Draft Document GL Entry বানায়?** — না। শুধু Submitted Document বানায়।
4. **Report-গুলো কোথা থেকে আসে?** — `tabGL Entry` থেকে Account/Date/Party দিয়ে Group/Sum করে।
5. **Cancel করলে GL Entry-র কী হয়?** — reverse হয় বা delete হয় (is_cancelled = 1)।
6. **`against` Field কী?** — একটা GL Entry-র বিপরীত Account-এর link, যাতে Dr-Cr জোড়া বোঝা যায়।

# Common Mistakes

❌ Draft Document-এ ভাবা Report-এ আসবে
❌ `is_cancelled = 0` Filter ভুলে যাওয়া (Developer)
❌ `company` Filter না দেওয়া
❌ GL Entry হাতে Edit করা — সবসময় Document দিয়ে করো
❌ GL Entry আর Stock Ledger Entry গুলিয়ে ফেলা
