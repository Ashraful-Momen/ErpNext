# Chapter 1 : Chart of Accounts (COA) কী?

প্রতিটা টাকার একটা Address থাকে। সেই Address-এর তালিকাই COA।

```
Money → Account → Chart of Accounts
```

Example — তোমার Company-এর Accounts:

```
Cash
Bank
Stock In Hand
Laptop (Fixed Asset)
Sales
Salary
Electric Bill
VAT
Accounts Receivable (Debtors)
Accounts Payable (Creditors)
```

এই পুরো List-টাই **Chart of Accounts**।

---

# ERPNext-এ কোথায়?

```
ERPNext → Accounting → Chart of Accounts
```

বাঁ পাশে একটা **Tree** দেখাবে — Group-এর ভিতরে Group, শেষে Ledger Account।

# গুরুত্বপূর্ণ Field

## 1. Account Number

```
1110 → Cash
1210 → Bank
1310 → Accounts Receivable
1510 → Stock In Hand
4110 → Sales
5110 → Salary Expense
```

হাজার Account Manage করা সহজ হয়।

## 2. Root Type (সবচেয়ে গুরুত্বপূর্ণ)

মাত্র ৫টা Root Type আছে:

```
Asset      → যা আছে
Liability  → যা দিতে হবে
Equity     → মালিকের
Income     → আয়
Expense    → খরচ
```

> **Root Type-ই ঠিক করে Account-টা Balance Sheet-এ যাবে নাকি Profit & Loss-এ।**

## 3. Account Type (আরেকটা গুরুত্বপূর্ণ)

Root Type-এর ভিতরে আরও specific nature:

```
Bank, Cash          → Asset
Receivable          → Asset (Customer-এর কাছে পাওনা)
Stock               → Asset (গুদামের মাল)
Fixed Asset         → Asset
Payable             → Liability (Vendor-কে দেনা)
Tax                 → VAT/Sales Tax
Cost of Goods Sold  → Expense
Depreciation        → Expense
```

> **Account Type দিয়ে ERPNext ঠিক করে — কোন document-এ কোন Account select করা যাবে।** যেমন Vendor Bill-এ শুধু `Payable` Account আসে।

## 4. Is Group vs Ledger

```
Is Group = Yes  → Parent (শুধু organize-এর জন্য, কোনো Entry হয় না)
Is Group = No   → Ledger (এখানেই Transaction হয়)
```

> **Group Account-এ কখনো GL Entry হয় না। শুধু Ledger Account-এ হয়।**

## 5. Company

Multi Company হলে প্রতিটা Company-র নিজস্ব COA। Account-এর সাথে Company link থাকে।

# Group (Parent) Structure

```
Assets (Group)
│
├── Current Assets (Group)
│      ├── Cash (Ledger)
│      ├── Bank (Ledger)
│      └── Stock In Hand (Ledger)
│
└── Fixed Assets (Group)
       └── Laptop (Ledger)

Liabilities (Group)
├── Current Liabilities (Group)
│      ├── Accounts Payable (Ledger)
│      └── VAT Payable (Ledger)

Equity (Group)
├── Capital (Ledger)

Income (Group)
├── Sales (Ledger)

Expenses (Group)
├── Salary (Ledger)
├── Rent (Ledger)
```

# Business Story

Owner $10,000 দিল → `Cash +10,000`, `Owner Capital +10,000`
Laptop $2,000 কিনলে → `Cash -2,000`, `Laptop +2,000`
Client Payment $3,000 → `Bank +3,000`, `Sales +3,000`
Salary $500 দিলে → `Bank -500`, `Salary Expense +500`

> **প্রতিটা Transaction শুধু COA-র Account-গুলোর মধ্যে Value স্থানান্তর করছে।**

---

# COA এবং ERPNext-এর সম্পর্ক

```
Sales Invoice  → Sales Account + Receivable
Purchase Invoice → Expense Account + Payable
Purchase Receipt → Stock Account + Stock Received But Not Billed
Payment Entry   → Bank/Cash Account + Receivable/Payable
```

> **ERPNext কখনো "টাকা" নিয়ে কাজ করে না; সবসময় Account-এর Balance নিয়ে কাজ করে।**

# Interview Questions

1. **Chart of Accounts কী?** — Company-র সব Financial Account-এর Master List (Tree)।
2. **Cash কোন Root Type?** — Asset।
3. **Sales কোন Root Type?** — Income।
4. **Salary কোন Root Type?** — Expense।
5. **VAT Payable কোন Root Type?** — Liability (Tax Account Type)।
6. **Group আর Ledger Account-এর পার্থক্য?** — Group শুধু organize-এর জন্য, Entry হয় না; Ledger-এই Transaction হয়।
7. **Root Type আর Account Type-এর পার্থক্য?** — Root Type broad (5টা), Account Type specific (Bank/Cash/Receivable...)।

---

# Common Mistakes

❌ Bank Account-কে Expense বানানো
❌ Sales Account-কে Asset বানানো
❌ Group Account-এ GL Entry দিতে চাওয়া
❌ Root Type ভুল দেওয়া — Report ভুল আসে
❌ Receivable/Payable Account-এ Account Type না দেওয়া — Invoice-এ selectই হবে না

# Module 1 শেষ করার পর যা বোঝা উচিত

* COA = Financial Accounts-এর Master Tree।
* প্রতিটা Account-এর আছে Root Type, Account Type, Is Group, Company।
* Root Type ঠিক করে Account Report-এ কোথায় যাবে।
* Group-এ Entry হয় না, শুধু Ledger-এ হয়।
* ERPNext-এর প্রতিটা Transaction শেষ পর্যন্ত GL Entry হয়ে COA Account-এ বসে।
