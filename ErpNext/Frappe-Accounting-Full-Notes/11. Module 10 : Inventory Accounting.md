# Module 10: Inventory Accounting — ERPNext Complete Note

আজ শিখব **গুদামের মাল (Inventory)** কীভাবে Accounting-এ হিসাব হয় — Perpetual Inventory, Valuation Method, COGS, আর Stock Ledger Entry।

> **Odoo-র Inventory Valuation-এর ERPNext সংস্করণ: Perpetual Inventory + Stock Ledger Entry + FIFO/Moving Average।**

---

# Chapter 1 : Inventory কী?

গুদামে থাকা মাল (Stock) — এটা একটা **Asset**।

```
Account: Stock In Hand (Account Type = Stock, Root Type = Asset)
```

> **মাল কেনা হলে Stock বাড়ে, বিক্রি হলে Stock কমে — প্রতিটা হিসাব Stock Ledger Entry-তে থাকে।**

---

# Chapter 2 : Perpetual Inventory কী?

**প্রতিটা লেনদেনের সাথে সাথে** (প্রতিটা Purchase Receipt, Delivery Note-এর সময়) Inventory-র Value আর GL Entry Update হয়।

```
Odoo-র "Perpetual" = ERPNext-র Default। আলাদা Enable করার দরকার নেই।
```

---

# Chapter 3 : Valuation Method

মালের দাম কীভাবে নির্ধারণ হয়:

| Method | নিয়ম |
| ------ | ----- |
| **FIFO** (First In First Out) | আগে কেনা মাল আগে বিক্রি |
| **Moving Average** | প্রতিটা কেনার পর Average দাম বদলায় |

> **ERPNext-এ সবচেয়ে বেশি ব্যবহৃত: Moving Average (সাধারণ) আর FIFO।**

---

# Chapter 4 : Inventory-র GL Entry Chain (Perpetual)

## Step 1 : Purchase Receipt (মাল ঢুকল)

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Stock In Hand | 10,000 | |
| Stock Received But Not Billed | | 10,000 |

## Step 2 : Purchase Invoice (Bill এলো)

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Stock Received But Not Billed | 10,000 | |
| Creditors | | 10,000 |

## Step 3 : Delivery Note (মাল বিক্রি হলো, গুদাম থেকে বেরোলো)

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Cost of Goods Sold | 6,000 | |
| Stock In Hand | | 6,000 |

> **এখানেই ERPNext-এর বড় পার্থক্য — COGS চেনা হয় Delivery Note-এ, Invoice-এ নয়। Odoo Invoice-এ চেনে, ERPNext Delivery-তে চেনে।**

## Step 4 : Sales Invoice (Revenue চেনে)

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Debtors | 11,500 | |
| Sales | | 10,000 |
| VAT Payable | | 1,500 |

---

# Chapter 5 : Sales Invoice-তে Update Stock On থাকলে

Delivery Note ছাড়া সরাসরি Sales Invoice-এ Update Stock On করলে — Step 3 + Step 4 একসাথে:

| Account | Debit | Credit |
| ------- | ----- | ------ |
| Debtors | 11,500 | |
| Sales | | 10,000 |
| VAT Payable | | 1,500 |
| Cost of Goods Sold | 6,000 | |
| Stock In Hand | | 6,000 |

---

# Chapter 6 : Stock Ledger Entry কী?

`Stock Ledger Entry` = Inventory-র প্রতিটা লেনদেনের রেকর্ড (Quantity + Value)।

```
Stock Ledger Entry (tabStock Ledger Entry)
├── Item Code
├── Warehouse
├── Qty In / Qty Out
├── Valuation Rate
├── Incoming/Outgoing Value
└── Voucher (Delivery Note, Purchase Receipt...)
```

> **GL Entry = টাকার হিসাব; Stock Ledger Entry = মালের Quantity+Value হিসাব। দুটো আলাদা, কিন্তু Perpetual-এ একসাথে চলে।**

# Chapter 7 : Stock Entry (ম্যানুয়াল মাল Adjust)

`Stock Entry` DocType দিয়ে হাতে মাল ঢোকানো/বের করা যায়:

| Stock Entry Type | কাজ |
| ---------------- | --- |
| Material Receipt | মাল ঢোকানো |
| Material Issue | মাল বের করা |
| Material Transfer | এক Warehouse থেকে আরেক |
| Manufacture | Production |
| Repack | মাল প্যাক বদল |

# Chapter 9 : Developer Perspective

Stock Value Query:

```python
stock_value = frappe.db.sql("""
    SELECT SUM(incoming_value - outgoing_value)
    FROM `tabStock Ledger Entry`

""", ("SW-001", "Main Warehouse"))
```

# Interview Questions

1. **Perpetual Inventory কী?** — প্রতিটা লেনদেনে Inventory Value + GL Entry সাথে সাথে Update।
2. **COGS কখন চেনা হয়?** — Delivery Note-এ (মাল বের হওয়ার সময়)।
3. **FIFO আর Moving Average-এর পার্থক্য?** — FIFO আগে কেনা মাল আগে; Moving Average গড় দাম।
4. **Stock Ledger Entry আর GL Entry-র পার্থক্য?** — Stock Ledger Quantity+Value; GL Entry টাকার Dr/Cr।
5. **Stock Received But Not Billed কী?** — মাল ঢুকেছে, Bill আসেনি — Bridge Account।

---

# Common Mistakes

❌ COGS Invoice-এ চেনার আশা করা (ERPNext Delivery-তে চেনে)
❌ Stock Account-এ Account Type `Stock` না দেওয়া
❌ Valuation Method না বোঝা (FIFO vs Moving Average)
❌ Stock Ledger Entry আর GL Entry গুলিয়ে ফেলা
❌ Warehouse-এর ভুল Account

---

# Cheat Sheet

```
মাল কেনা:   Purchase Receipt → Dr Stock / Cr SRBNB
Bill:        Purchase Invoice → Dr SRBNB / Cr Creditors
মাল বিক্রি:  Delivery Note   → Dr COGS / Cr Stock
Bill:        Sales Invoice   → Dr Debtors / Cr Sales + VAT
```
