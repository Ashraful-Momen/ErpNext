# Module 6: Bank & Reconciliation — ERPNext Complete Note

আজ শিখব **Bank Account** আর **Bank Reconciliation** — তোমার বইয়ের Bank Balance আর Bank-এর Statement মিলিয়ে ফেলা।

> **Odoo-র Bank Journal + Reconciliation-এর ERPNext সংস্করণ: Bank Account (Account Type = Bank) + Bank Reconciliation Tool + Bank Transaction।**

---

# Chapter 1 : Bank Account কী?

COA-তে Account Type = `Bank` এমন Account-ই Bank Account।

```
Account Name : Bank
Account Type : Bank
Root Type    : Asset
Account No   : 1210
```

> **কেন Account Type `Bank` দরকার?** কারণ Payment Entry-তে Bank Account select করতে, আর Bank Reconciliation-এ মেলাতে।

---

# Chapter 2 : Bank Reconciliation কী?

ব্যাংকের Statement (Bank-এর খাতা) আর ERPNext-এর GL Entry (তোমার খাতা) — দুইটা আলাদা।

```
ERPNext GL Entry-র Bank Balance    ≠    Bank Statement Balance
         (তোমার বই)                        (Bank-এর বই)
```

কারণ: Cheque Clear হতে দেরি হয়, Bank Charge, Interest, Timing difference।

**Reconciliation = এই দুইটা মিলিয়ে ফেলা।**

---

# Chapter 3 : ERPNext-এ কোথায়?

```
Accounting → Bank Reconciliation
```

অথবা

```
Accounting → Bank → Bank Account → Bank Reconciliation
```

---

# Chapter 4 : Bank Transaction কী?

`Bank Transaction` = Bank Statement-এর প্রতিটা লাইন (ERPNext-এ ঢোকানো হয়, নাহলে Bank Sync/API দিয়ে আসে)।

```
Bank Transaction (tabBank Transaction)
├── Transaction Date
├── Amount (Deposit/Withdrawal)
├── Description
└── (Reconciled কিনা status)
```

---

# Chapter 5 : Reconciliation-এর ধাপ

```
১. Bank Account select করো
২. Bank Transaction ঢোকাও (বা Bank Statement Import/Sync)
৩. "Match" করো — Bank Transaction ↔ GL Entry (Payment Entry)
৪. Unmatched Transaction-এর জন্য Journal Entry তৈরি করো (Bank Charge, Interest)
৫. মিলিয়ে গেলে Balance match হয়
```

---

# Chapter 6 : Real Scenario

Bank Statement-এ দেখলে:

```
১ জুলাই : Customer Payment   +5,750   (মিলবে Payment Entry-র সাথে)
২ জুলাই : Bank Charge        -50      (কোনো Entry নেই!)
৩ জুলাই : Interest            +20     (কোনো Entry নেই!)
```

ERPNext-এ:

```
+5,750 → Match করো Payment Entry-র সাথে
-50    → Journal Entry: Dr Bank Charge / Cr Bank
+20    → Journal Entry: Dr Bank / Cr Interest Income
```

> **এখন ERPNext-এর Bank Balance = Bank Statement Balance ✅**

# Interview Questions

1. **Bank Reconciliation কেন দরকার?** — বইয়ের Bank Balance আর Bank Statement মেলাতে।
2. **Bank Account আর Cash Account-এর পার্থক্য?** — Account Type `Bank` vs `Cash`।
3. **Unmatched Bank Charge কীভাবে ধরবে?** — Bank Transaction থেকে Journal Entry (Dr Bank Charge / Cr Bank)।
4. **Bank Transaction কী?** — Bank Statement-এর প্রতিটা লাইন ERPNext-এ।
5. **Match করলে কী হয়?** — Bank Transaction-এর সাথে GL Entry (Payment) লিংক হয়, balance মেলে।

---

# Common Mistakes

❌ Bank Account-এ Account Type `Bank` না দেওয়া
❌ Cheque Clear-এর দেরি না বুঝে "ভুল আছে" ভাবা
❌ Bank Charge/Interest-এর Journal Entry ভুলে যাওয়া
❌ ভুল Transaction-এর সাথে Match করা
❌ Reconciliation না করেও ভাবা "সব ঠিক আছে"

# Cheat Sheet

```
Bank Statement (Bank-এর বই)
        │
        ▼
Bank Transaction ERPNext-এ
        │
        ▼
Match ↔ GL Entry (Payment Entry)
        │
        ├── Matched → Done
        └── Unmatched → Journal Entry (Charge/Interest)
                │
                ▼
        Balance Match ✅
```
