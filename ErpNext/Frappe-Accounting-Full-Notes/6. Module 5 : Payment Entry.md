# Module 5: Payment Entry — ERPNext Complete Note

আজ শিখব **টাকা দেওয়া-নেওয়া** — Customer থেকে টাকা Receive, Vendor-কে টাকা Pay, আর নিজের Account-এর মধ্যে Transfer।

> **Odoo-র "Payment"-এর ERPNext সংস্করণ `Payment Entry`। এটা Invoice-এর Outstanding কমায়, আর GL Entry তৈরি করে Bank/Cash-এ টাকা বসায়।**

---

# Chapter 1 : Payment Entry কী?

Payment Entry = একটা Document যেটা টাকার আসা-যাওয়া (Bank/Cash) রেকর্ড করে, আর কোন Invoice-এর বিপরীতে তা লিংক করে।

---

# Chapter 2 : Payment Entry-র ৩টা Type

| Payment Type | অর্থ | GL Entry |
| ------------ | ---- | -------- |
| **Receive** | Customer/অন্য থেকে টাকা আসছে | Dr Bank / Cr Receivable |
| **Pay** | Vendor/অন্যকে টাকা দিচ্ছি | Dr Payable / Cr Bank |
| **Internal Transfer** | নিজের Account-এর মধ্যে | Dr Bank / Cr Cash |

---

# Chapter 3 : Payment Entry-এর ভিতরে কী থাকে?

`Payment Entry` DocType-এর Field:

```
Payment Type        → Receive / Pay / Internal Transfer
Party Type          → Customer / Supplier / Employee / Shareholder
Party               → কোন Customer/Vendor
Account Paid From   → Bank / Cash (টাকা কোথা থেকে)
Account Paid To     → (Receive-এ) Bank / Cash (টাকা কোথায় গেল)
Paid Amount         → কত দিল/পেল
Received Amount     → কত পেল
Mode of Payment     → Cash / Bank Transfer / Card...
Reference No        → Cheque/Transaction No
References (child)  → Payment Entry Reference
```

**Payment Entry Reference (child)**-এর Field:

```
Reference Type      → Sales Invoice / Purchase Invoice / Journal Entry
Reference Name      → নির্দিষ্ট Invoice
Total Amount        → Invoice-এর মোট
Outstanding Amount  → কত বাকি
Allocated Amount    → এই Payment-এ কত শোধ হচ্ছে
```

# Chapter 4 : Real Scenario

## Scenario 1 : Customer $5,750 দিল (Sales Invoice-র বিপরীতে)

```
Payment Type : Receive
Party        : Customer A
Account Paid To : Bank
References   : Sales Invoice SI-0001 ($5,750)
```

Submit করলে GL Entry:

```
Debit  Bank           5,750
Credit Accounts Receivable 5,750
```

> **Invoice-এর Outstanding কমে $5,750 → $0।**

## Scenario 2 : Vendor-কে $3,000 দিলাম

```
Payment Type : Pay
Party        : Supplier B
Account Paid From : Bank
References   : Purchase Invoice PI-0001
```

```
Debit  Accounts Payable  3,000
Credit Bank              3,000
```

## Scenario 3 : Cash থেকে Bank-এ $10,000

```
Payment Type : Internal Transfer
Account Paid From : Cash
Account Paid To   : Bank
```

```
Debit  Bank   10,000
Credit Cash   10,000
```

# Chapter 5 : Advance Payment

Invoice না থাকলে, আগে টাকা দেওয়া/নেওয়া — সেটা **Advance Payment**।

```
Payment Entry → is_advance = 1 (Advance)
```

> Advance Payment GL Entry:
> Receive Advance → `Dr Bank / Cr Advance From Customer`
> পরে Invoice হলে Advance দিয়ে Outstanding Adjust হয়।

---

# Chapter 6 : Payment Entry Lifecycle

```
Draft → Submitted → (GL Entry তৈরি)
        │
        └── Cancelled → GL Entry reverse, Outstanding ফেরত আসে
```

> **Payment Cancel করলে Invoice-এর Outstanding আবার বেড়ে যায় (ফেরত আসে)।**

# Interview Questions

1. **Payment Entry-র ৩টা Type কী?** — Receive, Pay, Internal Transfer।
2. **References Table-এর কাজ কী?** — কোন Invoice-এর বিপরীতে Payment তা লিংক করে, Outstanding কমায়।
3. **Advance Payment কী?** — Invoice ছাড়া আগে টাকা দেওয়া/নেওয়া; is_advance = 1।
4. **Payment Cancel করলে কী হয়?** — GL Entry reverse হয়, Invoice Outstanding ফেরত আসে।
5. **Internal Transfer কখন?** — Bank ↔ Cash / Bank ↔ Bank নিজের টাকা সরানো।

# Common Mistakes

❌ Receive-তে Account Paid From আর Account Paid To গুলিয়ে ফেলা
❌ References-এ ভুল Invoice ধরা — ভুল Outstanding কমে
❌ Paid Amount আর Received Amount না মেলানো
❌ Advance-কে সাধারণ Payment ধরা (is_advance ভুলে যাওয়া)
❌ Mode of Payment না দিলে Bank Reconciliation-এ ধরা পড়ে না

# Cheat Sheet

```
টাকা আসছে?
    ├── Receive  → Dr Bank / Cr Receivable
টাকা দিচ্ছি?
    ├── Pay      → Dr Payable / Cr Bank
নিজের Account?
    └── Internal Transfer → Dr Bank / Cr Cash
            │
            ▼
      References (Invoice link)
            │
            ▼
         Submit → GL Entry
```
