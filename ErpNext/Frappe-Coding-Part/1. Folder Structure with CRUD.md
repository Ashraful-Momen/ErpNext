তুমি যদি **Frappe 16 / ERPNext 16** নিয়ে কাজ করো, তাহলে এই structure মাথায় রাখো:

```text

│
├── apps/
│   ├── frappe/
│   │   ├── frappe/
│   │   ├── pyproject.toml
│   │   └── ...
│   │
│   └── my_app/
│       ├── my_app/
│       │   ├── __init__.py
│       │   ├── hooks.py
│       │   ├── api.py
│       │   ├── modules.txt
│       │   │
│       │   └── my_module/
│       │       ├── __init__.py
│       │       │
│       │       ├── doctype/
│       │       │   └── student/
│       │       │       ├── __init__.py
│       │       │       ├── student.py
│       │       │       ├── student.json

├── sites/
```

# 8. `student.json`

Location:

```text
apps/my_app/my_app/student_management/doctype/student/student.json
```

এখানে DocType-এর **metadata/configuration** থাকে।

যেমন:

```json
{
    "doctype": "DocType",
    "name": "Student",
    "module": "Student Management",
    "fields": [
        {
            "fieldname": "student_name",
            "fieldtype": "Data",
            "label": "Student Name"
        },
        {
            "fieldname": "email",
            "fieldtype": "Data",
            "label": "Email"
        },
        {
            "fieldname": "age",
            "fieldtype": "Int",
            "label": "Age"
        }
    ]
}
```

তবে **শুরুতে manually JSON লিখবে না**।

Desk থেকে DocType তৈরি করলে Frappe এটা generate করে।

# 9. `student.py`

এটাই তোমার সবচেয়ে গুরুত্বপূর্ণ Python file।

Location:

```text
apps/my_app/my_app/student_management/doctype/student/student.py
```

এখানে তুমি DocType-এর server-side logic লিখবে।

Example:

```python
import frappe
from frappe.model.document import Document


class Student(Document):

    def validate(self):
        if self.age < 18:
            frappe.throw("Student must be 18 or older")
```

এখানে:

```python
class Student(Document):
```

মানে এই class তোমার `Student` DocType-এর সাথে কাজ করবে।

# 10. CRUD-এর জন্য `student.py` সবসময় লাগবে না

এটা খুব important।

Frappe নিজেই CRUD operation দেয়।

তুমি চাইলে:

```python
student = frappe.get_doc("Student", name)
```

দিয়ে existing document নিতে পারো।

Create:

```python
student.insert()
```

Update:

```python
student.save()
```

Delete:

```python
frappe.delete_doc("Student", name)
```

অর্থাৎ Frappe ORM অনেক কাজ already handle করে।

# 11. Custom API কোথায় লিখবে?

ধরো Next.js থেকে API call করতে চাও।

তখন তুমি:

```text
apps/my_app/my_app/api.py
```

এখানে API রাখতে পারো।

Example:

```python
import frappe


@frappe.whitelist()
def get_students():

    return frappe.get_all(
        "Student",
        fields=[
            "name",
            "student_name",
            "email",
            "age"
        ]
    )
```

তারপর:

```text
/api/method/my_app.api.get_students
```

দিয়ে call করা যায়।

# 16. তোমার CRUD শেখার জন্য এখন শুধু এই structure মনে রাখো

```text
frappe-bench/
│
├── apps/
│   │
│   ├── frappe/              ← Framework
│   │
│   ├── erpnext/             ← ERPNext
│   │
│   └── my_app/              ← YOUR APP
│       │
│       └── my_app/
│           │
│           ├── api.py       ← Custom API
│           │
│           └── student_management/
│               │
│               └── doctype/
│                   │
│                   └── student/
│                       ├── student.py
│                       ├── student.json
│                       └── test_student.py
│
└── sites/
    └── your-site/
        ├── site_config.json
        ├── public/
        └── private/
```

### কোন file-এ কী?

| Location                       | কাজ                              |
| ------------------------------ | -------------------------------- |
| `apps/frappe/`                 | Frappe framework                 |
| `apps/erpnext/`                | ERPNext source                   |
| `apps/my_app/`                 | তোমার application                |
| `my_app/api.py`                | Custom API                       |
| `doctype/student/student.py`   | Student-এর business/server logic |
| `doctype/student/student.json` | DocType metadata                 |
| `test_student.py`              | Automated tests                  |
| `sites/site_name/`             | Site-specific configuration/data |
| `site_config.json`             | DB/site configuration            |
| `public/`                      | Public files                     |
| `private/`                     | Private files                    |

**এরপর CRUD শেখার সঠিক sequence হবে:**

```text
1. Bench structure
       ↓
2. Create custom App
       ↓
3. Create Module
       ↓
4. Create Student DocType
       ↓
5. Understand student.json
       ↓
6. Understand student.py
       ↓
7. Frappe ORM
       ↓
8. Create
       ↓
9. Read
       ↓
10. Update
       ↓
11. Delete
       ↓
12. Custom REST API
       ↓
13. Next.js → Frappe API
```

তুমি যেহেতু **Next.js frontend + Frappe backend** architecture শিখতে চাচ্ছো, এইভাবে শেখাই সবচেয়ে useful হবে—প্রথমে **Frappe-এর ভিতরের structure → DocType → ORM → API → তারপর Next.js integration**।
