# Step 1 : ERPNext App Install

```
Frappe Bench / Frappe Cloud

↓

ERPNext Install

↓

Site Create / Open

↓

First User = System Manager
```

ERPNext-এ Odoo-র মতো আলাদা আলাদা App Install করার দরকার নেই। **একটাই ERPNext App-এর ভিতরে সব Module আছে:**

```
Accounts    → হিসাব
Stock       → গুদাম
CRM         → লিড/অপportunity
Selling     → বিক্রি
Buying      → কেনা
HR          → কর্মচারী/পে-রোল
Projects    → প্রজেক্ট
Manufacturing → উৎপাদন
```

> **ERPNext Install মানেই সব Module Ready। শুধু User-দের Module Access দিতে হবে (Module Profile দিয়ে)।**

Install হলে ERPNext জিজ্ঞেস করবে —

```
তোমার Company কোন দেশের?
```

কারণ দেশ অনুযায়ী **Chart of Accounts (COA)** আর **Tax Template** আসবে।

# Step 5 : Chart of Accounts (COA)

## Localization — ERPNext নিজে দেয়

Company Create করার সময় দেশ Select করলে ERPNext নিজেই সেই দেশের Standard COA বসিয়ে দেয় —

```
Bangladesh / US / UK — দেশভেদে আলাদা
শত শত Ready Account
সঠিক Root Type + Account Type সহ
```

## দেখতে যাবে

```
ERPNext → Accounting → Chart of Accounts
```

## তোমার কাজ

```
১. Ready Account-গুলো একবার ঘেঁটে দেখো

২. তোমার Business-এর বিশেষ Account যোগ করো

   যেমন: "Software Sales", "Hosting Income"

৩. অদরকারি Account Disable/Archive না —

   ERPNext-এ Account Delete না করে Group Account-এর
   under-এ রেখে দাও বা ব্যবহার করো না
```

> **⚠️ নতুন Account বানানোর সময় সবচেয়ে গুরুত্বপূর্ণ হলো সঠিক Root Type আর Account Type দেওয়া। Type ভুল = Report ভুল।**

# Step 6 : Taxes Setup

```
ERPNext → Accounting → Taxes

↓

Sales Taxes and Charges Template
Purchase Taxes and Charges Template
Tax Category
```

## Check করো

Localization-এর সাথে Default Tax এসেছে —

```
VAT 15% (Sales)
VAT 15% (Purchase)
```

## তোমার কাজ

```
১. Default Sales Tax ঠিক আছে কিনা দেখো

২. Default Purchase Tax ঠিক আছে কিনা দেখো

   (Company-এ Default Tax Template সেট করো)
```

প্রতিটা Tax-এর ভিতরে Check —

```
Type              → On Net Total / On Previous Row Amount
Rate              → 15
Account Head      → কোন COA Account-এ যাবে
                    (VAT Payable / Input VAT)
```

> **⚠️ Tax Account Setup না থাকলে Invoice Submit করলে Tax-এর Entry ভুল জায়গায় যাবে বা Error দেবে।**

# Step 7 : Journal Entry Types / Journals Setup

ERPNext-এ Odoo-র মতো আলাদা "Journal" Master নেই। এর বদলে **Journal Entry Type** আছে —

```
ERPNext → Accounting → Journal Entry

↓

Voucher Type:

Journal Entry, Bank Entry, Cash Entry,
Credit Card Entry, Contra Entry, Opening Entry,
Depreciation Entry, Exchange Rate Revaluation...
```

## প্রতিটা Check করো

```
Default Voucher Type → সাধারণত "Journal Entry"

Opening Entry        → Opening Balance-এর জন্য

Bank Entry           → Bank জড়িত Transaction-এর জন্য
```

# Step 8 : Bank Account Setup (খুব গুরুত্বপূর্ণ)

## নতুন Bank Account যোগ করা

```
ERPNext → Accounting → Bank Account → New
```

ভরো —

```
Account Name     → Bank DBBL
Bank             → Dutch Bangla Bank
Account Number   → 1234567890
Branch Code
Company          → তোমার Company
Default Account  → COA-তে Bank Account (Auto create করতে পারো)
```

## Mode of Payment

```
ERPNext → Accounting → Mode of Payment

↓

Bank → Default Account = Bank Account
Cash → Default Account = Cash Account
Card → Default Account = Bank Account
```

> **এই Account ঠিক থাকলে Payment Entry আর Bank Reconciliation মকরের মতো চলবে।**

## একাধিক Bank Account?

```
প্রতিটা Bank Account-এর জন্য

আলাদা COA Account (Bank DBBL, Bank BRAC)

আর Mode of Payment (Bank Transfer DBBL, Bank Transfer BRAC)
```

# Step 10 : Users ও Access Rights

## কে কী পারবে — ঠিক করে দাও

```
ERPNext → Users and Permissions → User

↓

User খোলো → Roles Tab
```

## ERPNext-এর Role-গুলো

```
Accounts User     → Invoice/Bill/Payment বানাতে পারবে
Accounts Manager  → Entry, Reconcile, Report — সব
Stock User        → Stock Transaction
Sales User        → Quotation, Sales Order, Invoice
Purchase User     → PO, Purchase Receipt, Invoice
System Manager    → Setup + সবকিছু
```

## Real Life Rule

```
Sales Team   → Sales User (Invoice বানাবে)
Junior Acc   → Accounts User
Senior Acc   → Accounts Manager
তুমি (Lead)  → System Manager
```

> **⚠️ সবাইকে System Manager দিও না। একজন ভুল Entry দিলে সবার Report ভুল।**

# Step 11 : Opening Balance (যদি পুরোনো ব্যবসা হয়)

## নতুন Company হলে

এই Step Skip করো। Owner Capital-এর Entry দিলেই শুরু —

```
Dr Bank / Cr Capital
```

## পুরোনো ব্যবসা থেকে আসলে

পুরোনো খাতার Closing Balance ঢোকাও —

```
ERPNext → Accounting → Journal Entry → New

Voucher Type: Opening Entry
Date: Fiscal Year-এর প্রথম দিন
```

Example Entry —

```
Dr Bank                        50,000
Dr Inventory                   20,000
Dr Accounts Receivable         10,000   (Party দিতে ভুলো না!)
    Cr Accounts Payable              15,000  (Party সহ)
    Cr Loan                          25,000
    Cr Opening Balance Equity        40,000
```

```
Debit = Credit মিলতে হবে ✓
```

> **⚠️ Receivable/Payable লাইনে Party না দিলে পরে Customer-Vendor-এর পাওনা-দেনা Track হবে না।**

# Interview Questions

### 1. ERPNext Install-এর পর প্রথম কাজ কী?

**উত্তর:** Company Setup — বিশেষ করে Currency, Country, আর VAT Number। Currency পরে বদলানো কঠিন, আর Country অনুযায়ী COA/Tax আসে।

### 2. ERPNext-এ Odoo-র মতো আলাদা Module Install করতে হয়?

**উত্তর:** না। ERPNext একটাই App, তার ভিতরে সব Module Ready। User-দের Role/Module Profile দিয়ে Access Control করতে হয়।

### 3. Localization কী?

**উত্তর:** দেশ অনুযায়ী Ready-made COA আর Tax Template — Company Create করার সময় Country Select করলে ERPNext নিজে বসিয়ে দেয়।

### 4. পুরোনো ব্যবসার Data কীভাবে ERPNext-এ আনবে?

**উত্তর:** Opening Journal Entry — Fiscal Year-এর প্রথম দিনের Date-এ, Opening Entry Voucher Type-এ, সব Account-এর Balance সহ (Debit = Credit মিলিয়ে)।

### 5. ERPNext-এ Bank Account Setup-এ কী কী লাগে?

**উত্তর:** Bank Account DocType-এ Account Number, Bank Name, Default COA Account; আর Mode of Payment-এ Default Account Link।

# Common Mistakes (Setup-এ)

❌ Currency ভুল দেওয়া — পরে সব Entry ভুল মুদ্রায়।

❌ Fiscal Year Setup না করা — Report ভুল Period-এ আসে।

❌ Tax Account Setup না করে Invoice Submit করা।

❌ সবাইকে System Manager Access দেওয়া।

❌ Opening Balance-এ Party না দেওয়া — পাওনা-দেনা Track হারায়।

❌ Default COA না দেখে নতুন Account বানানো — Duplicate হয়।

❌ Test না করে Live যাওয়া — প্রথম Invoice-এই ভুল ধরা পড়ে।

❌ Account Type ভুল দেওয়া — Report ভুল আসে।
