# Setup Step 8 : Accounting Settings A to Z — ERPNext 16

**Series: ERPNext 16 Perfect Setup (Step 8 of 11) — File 0.10**

> **এই একটা Page-ই পুরো Accounting-এর Control Room। প্রতিটা Switch-এর দুইটা দিক আছে — চালু করলে কী পাবে, আর চালু না করলে কী হারাবে। এই Note-এ প্রতিটা Section এভাবেই দেওয়া।**

# কোথায় যাবে

```
ERPNext → Accounting → Accounting Settings
```

Page-টা লম্বা। Section ধরে ধরে যাই।

---

# SECTION 1 : Accounts Settings

## Delete Accounting and Stock Entries

```
কী:      Submitted Journal Entry / Stock Entry Delete করতে পারবে কিনা

Default: Off (সুপারিশ)

করলে:   ভুল Entry Cancel করে আবার করা যায়
        → Audit Trail ভালো থাকে

চালু করলে:
   ❌ Submitted Entry Delete করা যাবে
   → Audit-এ সমস্যা হতে পারে
```

---

## Enable Perpetual Inventory

```
কী:      প্রতিটা Stock Move-এ সাথে সাথে GL Entry হয়

Default: On (সুপারিশ)

করলে কী হয়:
   ✅ Purchase Receipt → Dr Stock / Cr Stock Received But Not Billed
   ✅ Delivery Note → Dr COGS / Cr Stock
   ✅ COGS নিজে বের হয়

বন্ধ করলে:
   ❌ Stock আর Accounting আলাদা
   ❌ COGS হাতে বসাতে হয়
```

---

## Allow Negative Stock

```
কী:      Stock ০-এর নিচে গেলেও Delivery Note Submit হবে

Default: Off (সুপারিশ)

চালু করলে:
   ✅ দ্রুত Delivery হয়

বন্ধ করলে:
   ✅ Stock-Out হলে System আটকায়
   ✅ ভুল Delivery ধরা পড়ে
```

---

# SECTION 2 : Taxes

## Default Taxes (Company-এ)

```
ERPNext → Settings → Company → Default Tax Template

Default Sales Tax      → Sales Taxes and Charges Template
Default Purchase Tax   → Purchase Taxes and Charges Template
```

```
করলে কী হয়:
   ✅ Invoice/Bill-এ Tax নিজে চলে আসে
   ✅ কেউ ভুলে Tax বাদ দিতে পারে না

না করলে কী হয়:
   ❌ প্রতিটা Invoice-এ হাতে Tax বসাতে হবে
   ❌ একদিন ভুলে যাবে → VAT কম গেল
```

> **করবে: ✅ অবশ্যই।**

---

## Rounding Method

```
ERPNext → Accounting → Accounts Settings

→ Rounding Method
```

```
কী:      Tax/Amount হিসাবের দশমিক কীভাবে Round হবে

"Round Row-wise" বা "Round Grand Total"

কোনটা দেবে:
   দেশের Tax Rule যা বলে তাই
```

```
ভুল দিলে:
   Invoice Total-এ ১-২ পয়সা এদিক-সেদিক
   → Customer-এর System-এর সাথে মিলবে না
```

---

## Cash Basis Tax

```
ERPNext-তে Default: Accrual Basis

Cash Basis Tax-এর জন্য Tax Category / Special Template লাগে
```

```
চালু করলে:        টাকা না পেলে Tax-ও ধরা হবে না
না করলে (Default): Invoice-ই Tax-এর ঘটনা
```

> **⚠️ এটা এলোমেলো চালু করো না। পুরো Tax Report-এর Logic বদলে যায়। Tax Advisor-কে জিজ্ঞেস করে।**

# SECTION 4 : Default Accounts

```
ERPNext → Settings → Company → Default Accounts
```

```
Default Receivable Account   → Debtors
Default Payable Account      → Creditors
Default Bank Account         → Bank
Default Cash Account         → Cash
Default Cost of Goods Sold   → Cost of Goods Sold
Default Stock Adjustment     → Stock Adjustment
```

```
কী কাজে:
   নতুন Customer/Vendor/Item বানালে
   এই Account-গুলো নিজে বসে যায়

ভুল থাকলে কী হয়:
   ❌ সব Invoice-এর Receivable ভুল Account-এ
   ❌ Aged Report ভুল
   ❌ Balance Sheet ভুল
```

> **🚨 Localization-এ যেটা এসেছে সেটাই সাধারণত ঠিক। না বুঝে হাত দিও না। তবে একবার খুলে দেখে নাও কোন Account বসে আছে।**

# SECTION 5 : Advanced Features

## Analytical Accounting / Accounting Dimensions

```
ERPNext → Accounting → Accounting Dimensions

Enable করো:
   Cost Center
   Department
   Project
   (আর Custom Dimension — যেমন Branch)
```

```
কী:      Project/Department-ভিত্তিক খরচ Track
         ("কী খরচ" না, "কার জন্য খরচ")

চালু করলে:
   ✅ প্রতিটা Entry-তে Project/Cost Center Tag দেওয়া যায়
   ✅ Project-ভিত্তিক Profit Report পাও

কখন চালু করবে:
   একাধিক Project/Client থাকলে (Software Company = ✅)
   একটাই Product/Service হলে → লাগবে না
```

---

## Budget Management

```
ERPNext → Accounts → Budget

কী:      Plan vs Actual (কত ভাবছিলে, কত হলো)

কখন চালু করবে:
   Management Budget নিয়ে কাজ করে → ✅
   ছোট Team, মৌখিক Budget → এখন না, পরে

মনে রাখবে: Cost Center ছাড়া কাজ করে না
```

---

## Asset Management / Deferred Revenue

```
ERPNext → Assets → Asset Settings

কী:      Fixed Asset-এর Auto Depreciation Schedule
         + অগ্রিম Income-এর Auto Release

কখন চালু করবে:
   Laptop/Vehicle/Machine আছে → ✅
   Annual Subscription/Contract বিক্রি করো → ✅
```

---

## Multi-Currencies

```
ERPNext → Accounting → Currency

কী:      Dollar/Euro-তে Invoice, Taka-তে হিসাব

কখন চালু করবে:
   বিদেশি Client/Vendor থাকলে → ✅ অবশ্যই
   শুধু দেশের ভিতরে কাজ → না

চালু করলে কী হয়:
   Invoice-এ Currency Select করতে পারবে
   Exchange Gain/Loss Auto হবে
```

# SECTION 6 : Lock Dates (মাস শেষে ব্যবহার করবে)

```
ERPNext → Accounting → Accounting Settings

→ Accounts Frozen Till Date
```

```
কী:      কোন Date-এর আগের Entry আর কেউ বদলাতে পারবে না

Setup-এর সময় কী করবে:
   → এখন কিছু দিও না
   → প্রথম মাস শেষে প্রথম Lock Date দেবে

নিয়ম:
   মাস শেষ → Report Final → Tax Paid → Lock
   এই ক্রম কখনো উল্টাবে না
```

# Common Mistakes

❌ সব Switch চালু করে ফেলা — "যত ফিচার তত ভালো" না।

❌ Default Accounts নিজে বদলে দেওয়া।

❌ Cash Basis না বুঝে চালু করা।

❌ Invoice Terms ফাঁকা রাখা।

❌ Lock Date Setup-এর দিনেই দেওয়া — নিজেরই Entry আটকে যাবে।

❌ Multi-Currency চালু করে Exchange Rate Update না করা।

❌ Perpetual Inventory বন্ধ রাখা — Stock আর Accounting আলাদা হয়ে যায়।

```
□  Save চেপেছি ✅
```
