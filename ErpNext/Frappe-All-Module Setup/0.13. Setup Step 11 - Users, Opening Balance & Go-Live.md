# PART A : Users & Access Rights

## কোথায়

```
ERPNext → Users and Permissions → User

↓

User খোলো → Roles Tab
```

## ERPNext-এর Role-গুলো — প্রতিটা কী পারে

### 1. Accounts User

```
পারবে:    Invoice, Bill, Payment Entry, Sales/Purchase Invoice বানাতে

পারবে না: Journal Entry (Accounts Manager ছাড়া), Settings বদলাতে,
          Reconciliation Permission থাকলে Reconcile
```

```
কাকে দেবে:
   Sales Team (Invoice বানাবে)
   Junior Accountant (Daily Data Entry)
```

### 2. Accounts Manager

```
পারবে:    সব — Journal Entry, Bank Reconcile,
          Asset, Report, Adjustment, Period Closing

কাকে দেবে:
   Senior Accountant / Finance Manager
```

### 3. Sales User / Purchase User

```
Sales User    → Quotation, Sales Order, Sales Invoice
Purchase User → Purchase Order, Purchase Receipt, Purchase Invoice
```

### 4. Stock User / Stock Manager

```
Stock User    → Stock Entry, Delivery Note, Purchase Receipt
Stock Manager → Stock Settings, Reconciliation
```

### 5. System Manager

```
পারবে:    ERPNext-এর সব + Configuration
          (COA, Tax, Company, Role Permission)

কাকে দেবে:
   শুধু তুমি (Team Lead) + ১ জন Backup
   → ২ জনের বেশি কখনো না
```

---

## Access দেওয়ার Golden Rules

```
Rule 1: Minimum Access
   → যা লাগবে, ঠিক ততটুকুই
   → "ওসাধারণ মানুষ, Admin দিয়ে দেই" — 🚫 কখনো না
```

```
Rule 2: এক কাজ, এক দায়িত্ব
   → যে Invoice বানায়, সে যেন Settings ছুঁতে না পারে
   → যে Settings পারে, সে দিনে ১০০টা Entry করে না
```

```
Rule 3: চাকরি ছাড়লে সেই দিনই Access বন্ধ
   → User Delete না → Uncheck Roles / Deactivate করো
   → তার করা Entry-র History থেকে যায়
```

```
ভুল Access দিলে কী হয়:
   ❌ Junior ভুলে COA-র Account বদলে দিল → সব Report ভুল
   ❌ কেউ পুরোনো মাসের Entry Cancel করে দিল → Tax Report ফেল
   ❌ কেউ Bank Reconcile গুলিয়ে দিল → মাস শেষে আগুন
```

# PART B : Opening Balance

## আগে সিদ্ধান্ত নাও

```
নতুন Company?
   → Opening Balance লাগবে না
   → শুধু Owner Capital Entry: Dr Bank / Cr Capital
   → PART C-তে সরাসরি যাও
```

```
পুরোনো ব্যবসা, নতুন ERPNext?
   → পুরোনো System/খাতার Closing Balance ঢোকাতে হবে
   → নিচের পুরো PART পড়ো
```

---

## কোন Date-এ ঢোকাবে?

```
নিয়ম: Fiscal Year-এর প্রথম দিন

যেমন: Fiscal Year শুরু ১ জুলাই ২০২৬
   → Opening Entry-র Date: ০১-০৭-২০২৬
```

```
কেন: নতুন বছরের প্রথম দিনে সব Balance Ready থাকে
     বছরের Report পরিষ্কার থাকে
```

## ধাপে ধাপে Opening Entry

```
ERPNext → Accounting → Journal Entry → New
```

```
Voucher Type: Opening Entry
Date: ০১/০৭/২০২৬ (Fiscal Year-এর প্রথম দিন)
Reference: "Opening Balance FY 2026-27"
```

## কী ঢোকাবে — পুরোনো Trial Balance থেকে

### Asset-গুলো (Debit)

```
Dr Bank                        50,000
Dr Cash                         5,000
Dr Accounts Receivable         10,000  ← Party দিতে হবে!
Dr Inventory                   20,000
Dr Laptop/Fixed Asset          15,000
```

### Liability-গুলো (Credit)

```
    Cr Accounts Payable              15,000  ← Party সহ!
    Cr Bank Loan                     25,000
    Cr VAT Payable                    3,000
```

### Equity (Credit — বাকিটা বলে দেয়)

```
    Cr Opening Balance Equity        57,000
```

## শেষে Check

```
Debit Total  = 100,000
Credit Total = 100,000  ✓

না মিললে → পুরোনো Trial Balance আবার দেখো
কোনো Account বাদ পড়েছে
```

## 🚨 Opening Balance-এর ৩টা মারাত্মক ভুল

### ভুল 1 : Receivable/Payable-এ Party না দেওয়া

```
করলে কী হয়:
   Entry তো হলো, কিন্তু ERPNext জানে না
   কোন Customer-এর কত পাওনা
   → নতুন Payment মেলানো যায় না
   → Accounts Receivable Report ফাঁকা

সমাধান: প্রতিটা Customer/Vendor-এর জন্য
   আলাদা Line, প্রতিটায় Party সহ
```

### ভুল 2 : Inventory দুইবার ঢোকানো

```
করলে কী হয়:
   Opening Entry-তেও Inventory দিলে,
   আবার Stock Reconciliation-ও করলে
   → Inventory দ্বিগুণ দেখায়

সমাধান:
   Perpetual Inventory হলে Stock Reconciliation দিয়ে ঢোকাও,
   Opening Journal Entry-তে Inventory বাদ দাও
   → একটাই রাস্তা বেছে নাও
```

### ভুল 3 : Opening আবার ঢোকানো

```
করলে কী হয়:
   একই Balance দুইবার Entry → সব দ্বিগুণ

সমাধান:
   Opening Entry Submit করার পর
   Screenshot/PDF রেখে দাও
   → "হয়ে গেছে"-র প্রমাণ থাকলে কেউ আবার করবে না
```

# Common Mistakes (শেষ বারের মতো)

❌ সবাইকে System Manager দেওয়া।

❌ Opening Balance-এ Party বাদ দেওয়া।

❌ Opening দুইবার Entry করা।

❌ Test না করে Live যাওয়া।

❌ Test Entry Delete না করা — প্রথম Report-এ Test Data।

❌ Go-Live-এর পর মাস শেষে Lock Date না দেওয়া।

❌ চাকরি ছাড়া User-এর Access খোলা রাখা।
