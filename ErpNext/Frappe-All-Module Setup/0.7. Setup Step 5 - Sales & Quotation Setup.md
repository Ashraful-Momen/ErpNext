# Chapter 1 : Sales Flow আগে বুঝো

```
Quotation তৈরি

   ↓ (Client-কে Email/Portal-এ পাঠালে)

Client Accept করল

   ↓ (Submit)

Sales Order

   ↓

Delivery Note (পণ্য হলে — Inventory থেকে Auto)

   ↓

Sales Invoice (Auto Create / Manual)

   ↓

Payment Entry → Paid ✅
```

> **Setup-এর লক্ষ্য একটাই — এই Flow-এ তোমার হাত যত কম লাগে, তত ভালো।**

# Chapter 2 : Selling Settings — প্রতিটা Option

## কোথায়

```
ERPNext → Selling → Settings
```

---

## SECTION : Quotation & Orders

### 1. Customer Naming By

```
কী:      Customer-এর ID কীভাবে হবে

         Naming Series → CUST-00001
         Customer Name → Customer A
```

```
করলে:   Auto Numbering → Search সহজ
না করলে: নাম দিয়ে Search → Duplicate হতে পারে
```

### 2. Default Quotation Validity

```
কী:      Quotation কত দিন Valid থাকবে (যেমন: ৩০ দিন)

করলে:   পুরোনো Quotation নিজে Expire হয়

না করলে: ২ বছর আগের দামে আজ Order দিলে করার উপায় নেই
```

### 3. Sales Order Required

```
কী:      Sales Invoice বানাতে আগে Sales Order লাগবে কিনা

চালু করলে: Sales Flow discipline থাকে
বন্ধ করলে: সরাসরি Invoice → দ্রুত, কিন্তু Track কম
```

---

## SECTION : Pricing

### 4. Price Lists 🚨

```
কী:      Customer-ভেদে আলাদা দাম

         যেমন —
         Retail Customer  → $100
         Corporate Client → $85
         Distributor      → $70
```

```
কোথায়:
   ERPNext → Stock → Price List

   তারপর Customer-এর Profile-এ Default Price List বসাও
```

```
করলে কী হয়:
   ✅ Customer Select করলেই তার দাম নিজে আসে
   ✅ Sales Team-কে দাম মনে রাখতে হয় না

না করলে:
   প্রতিবার হাতে দাম বদলানো
   → একদিন Corporate-কে Retail দামে Invoice গেল
   → লোকসান!
```

### 5. Item Price

```
ERPNext → Stock → Item Price

→ Item + Price List + Rate
→ Customer-ভেদে Special Rate দেওয়া যায়
```

### 6. Discount

```
ERPNext-এ Invoice Line-এ Discount % সরাসরি দেওয়া যায়

করলে:   Client দেখে "৫% Discount পেলাম" → খুশি
```

## SECTION : Product & Delivery

### 7. Item Variants

```
কী:      এক Item-এর ভার্সন — Color/Size/Edition

         যেমন: Laptop Bag (Black / Brown)
```

```
কখন চালু করবে: ভ্যারিয়েন্ট থাকলে
কখন না:        প্রতিটা পণ্য এক রকম → অদরকারি জটিলতা

### 8. UOM (Unit of Measure)

```

# Chapter 3 : Item Setup (Sales-এর দিক থেকে)

```
ERPNext → Stock → Item → New
```

## গুরুত্বপূর্ণ Field

### 1. Maintain Stock

```
Yes → পণ্য (Stock যাবে-আসবে)
No  → Service (Stock নেই)
```

### 2. Is Sales Item

```
Yes → Sales Order/Sales Invoice-এ আসবে
```

### 3. Default Selling Price / Valuation Rate

```
Standard Selling Rate → List Price
Valuation Rate        → Cost Price (Stock Item-এর)
```

### 4. Income Account 🚨

```
কোন COA Account-এ এই Item-এর Sales যাবে

যেমন: "Software License Sales"

করলে:   P&L-এ দেখবে কোন পণ্যে কত আয়

না করলে: সব এক Account-এ গাদা → বিশ্লেষণ শেষ
```

# Common Mistakes

❌ Customer-এ Default Price List না দেওয়া — প্রতিবার হাতে দাম।

❌ Customer-এ Payment Terms না দেওয়া — Due Date হারায়।

❌ Item-এ Income Account ফাঁকা — সব Sales এক গাদায়।

❌ Service Item-এ Maintain Stock=Yes রাখা।

❌ Template না বানিয়ে একই Proposal বারবার টাইপ করা।

❌ Price List না বানিয়ে হাতে দাম বদলানো — একদিন লোকসানে বিক্রি হয়েই যাবে।

# Checklist

```
Settings—

□  Customer Naming By = Naming Series
□  Default Quotation Validity দিন ঠিক করেছি
□  Sales Order Required — লাগলে চালু

Pricing—

□  Price List বানিয়েছি (Retail/Corporate/Distributor)
□  Item Price দিয়েছি
□  Discount Policy ঠিক

Item & Customer—

□  প্রতিটা Item-এ Maintain Stock সঠিক
□  Is Sales Item = Yes
□  Income Account দেওয়া
□  Default Selling Rate দেওয়া

Customer Master—

□  Customer Group ঠিক
□  Territory ঠিক
□  Default Price List বসানো
□  Default Payment Terms বসানো

Test—

□  Quotation → Sales Order → Delivery Note → Invoice এক Flow-এ হয়েছে
```
