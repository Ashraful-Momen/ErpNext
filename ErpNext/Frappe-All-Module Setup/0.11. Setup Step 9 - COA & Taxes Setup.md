## কোথায়

```
ERPNext → Accounting → Chart of Accounts
```

## আগে এই ৩টা কাজ

```
১. Localization-এ যা এসেছে, পুরোটা একবার Scroll করে দেখো
   → ৮০% Account তোমার আগে থেকেই বানানো

২. অদরকারি Account Disable করো না —

৩. তারপর যা Missing, শুধু সেগুলো নতুন বানাও
```

## নতুন Account বানানো — প্রতিটা Field

### 1. Account Number

```
কী:      Account-এর নম্বর (যেমন: 1110, 4110)

কেন দরকার:
   হাজার Account-এর মধ্যে Number দিয়ে Sort/Search হয়
   Report-এ Number অনুযায়ী সাজে
```

```
Convention (Localization মেনে চলো):

   1xxx → Asset
   2xxx → Liability
   3xxx → Equity
   4xxx → Income
   5xxx/6xxx → Expense
```

```
ভুল করলে: Report-এ Account এলোমেলো জায়গায় বসে
```

---

### 2. Account Name

```
কী:      মানুষের পড়ার নাম (যেমন: "Software Sales")

Rule: এমন নাম দাও যাতে ৬ মাস পরেও বোঝো কীসের Account

❌ "Sales1", "New Account", "Test"
✅ "Software License Sales", "AWS Hosting Expense"
```

---

### 3. Root Type 🚨 (সবচেয়ে গুরুত্বপূর্ণ)

```
কী:      এই Account কোন broad Category-র

         Asset / Liability / Equity / Income / Expense

কেন:     Root Type-ই ঠিক করে —
         ১. Balance Sheet-এ যাবে, নাকি P&L-এ
         ২. বছর শেষে শূন্য হবে, নাকি বয়ে যাবে
         ৩. Report-এর কোন লাইনে বসবে
```

| Root Type | কোথায় যায় | বছর শেষে |
|---|---|---|
| Asset | Balance Sheet | বয়ে যায় |
| Liability | Balance Sheet | বয়ে যায় |
| Equity | Balance Sheet | বয়ে যায় |
| Income | P&L | শূন্য হয় |
| Expense | P&L | শূন্য হয় |

```
ভুল Root Type দিলে কী হয়:
   ❌ Sales-কে Asset করলে → Sales Balance Sheet-এ যাবে,
      P&L-এ Income দেখাবে না → মালিক ভাববে লাভ নেই
   ❌ Expense-কে Asset করলে → লাভ ফুলিয়ে দেখাবে
      → ভুল Tax → জরিমানা
```

---

### 4. Account Type 🚨 (আরেকটা গুরুত্বপূর্ণ)

```
কী:      এই Account-এর specific nature

         Bank, Cash, Receivable, Payable, Stock,
         Cost of Goods Sold, Depreciation, Tax...

কেন:     ERPNext ঠিক করে —
         কোন document-এ কোন Account select হবে
```

```
ভুল Account Type দিলে:
   ❌ Sales Invoice-এ Receivable Account আসবে না
   ❌ Payment Entry-এ Bank Account select হবে না
   ❌ Purchase Invoice-এ Payable Account আসবে না
```

---

### 5. Is Group

```
Is Group = Yes  → Parent (শুধু organize-এর জন্য, Entry হয় না)
Is Group = No   → Ledger (এখানেই Transaction হয়)
```

---

### 6. Account Currency

```
কী:      এই Account শুধু একটা মুদ্রায় চলবে
         (যেমন: USD Bank Account)

ফাঁকা রাখলে: Company Currency-এ চলে
Multi-Currency থাকলে বিদেশি Bank-এ Set করো
```

## তোমার Company-র জন্য যে Account-গুলো বানাবে (Example)

```
Income:
   4110 → Software License Sales
   4120 → Consulting Income
   4130 → Support & Maintenance Income
```

```
Expense:
   5110 → Salary Expense
   5120 → AWS / Hosting Expense
   5130 → Internet Expense
   5140 → Office Rent
```

```
কেন আলাদা আলাদা Income Account:
   → P&L-এ দেখবে কোন Line-এ বেশি আয়
   → "Software বেশি চলে, নাকি Consulting?" — উত্তর পাবে
```

> **নিয়ম: যে খরচ/আয় মাসে ২-৩ বারের বেশি হয়, তার নিজের Account দাও। বছরে একবার হয়, General Account-এ রাখো।**

# PART B : Taxes Setup

## কোথায়

```
ERPNext → Accounting → Taxes

↓
Sales Taxes and Charges Template
Purchase Taxes and Charges Template
Tax Category
```

## প্রতিটা Field

### 1. Title

```
কী:      Template-এর নাম (যেমন: "VAT 15%")
```

---

### 2. Tax Type / Charge Type

```
On Net Total          → Subtotal-এর উপর %
On Previous Row Amount → আগের Tax-এর উপর
Actual                → Fixed Amount
```

---

### 3. Account Head 🚨

```
কী:      এই Tax-এর টাকা কোন COA Account-এ জমা হবে

Sales Tax হলে:
   → VAT Payable (Output Tax Account)

Purchase Tax হলে:
   → Input VAT (Input Tax Account)
```

```
না দিলে / ভুল দিলে কী হয়:
   ❌ Invoice Submit-এ Tax-এর লাইন ভুল Account-এ যায়
   ❌ Tax Report ফাঁকা বা ভুল আসে
   ❌ মাস শেষে সরকারকে কত দেবে — জানা যায় না
```

> **এটাই Tax Setup-এর সবচেয়ে বড় ভুলের জায়গা। Tax Template বানানোর পর একটা Test Invoice Submit করে GL Entry-তে Tax Line কোন Account-এ গেছে — দেখে নাও।**

---

### 4. Rate

```
কী:      15 মানে 15%

VAT 15% হলে: 15
```

---

### 5. Included in Print / Included in Paid Amount

```
কী:      Invoice-এ Tax আলাদা দেখাবে, নাকি দামের ভিতরে

"Include in Print" = No  → ১০০০ + ১৫০ = ১১৫০
"Include in Print" = Yes → ১১৫০-র ভিতরে ১৫০ Tax

ভুল Select করলে পুরো দাম বদলে যাবে
```

# PART C : Tax Category (Advanced)

```
ERPNext → Accounting → Tax Category

কী:      Customer/Vendor/Item অনুযায়ী Tax Template বদলে দেওয়ার Rule
```

```
কখন লাগে:
   বিদেশি Customer → VAT 0% (Export)
   দেশি Customer   → VAT 15%
   → Tax Category বসিয়ে দিলে Invoice-এ নিজে বদলে যায়
```

```
না বসালে: প্রতিবার হাতে Tax বদলাতে হবে → একদিন ভুল হবেই
```

# Common Mistakes

❌ Root Type ভুল দেওয়া — COA-র সবচেয়ে মারাত্মক ভুল।

❌ Account Type ভুল দেওয়া — Document-এ Account আসে না।

❌ Tax Account ফাঁকা রাখা — Tax Report ভেঙে যায়।

❌ Tax Included/Excluded গুলিয়ে ফেলা — দামই বদলে যায়।

❌ Group Account-এ Entry দেওয়ার চেষ্টা — ERPNext Error দেবে।

❌ প্রতিটা ছোট খরচের জন্য আলাদা Account — COA অগোছালো হয়।

❌ Tax Category না বানিয়ে বিদেশি Client-এ হাতে Tax বদলানো।

# Checklist

```
COA—

□  Localization-এর সব Account ঘেঁটে দেখেছি
□  নিজের Income Account-গুলো বানিয়েছি (সঠিক Root Type)
□  নিজের Expense Account-গুলো বানিয়েছি (সঠিক Root Type)
□  Account Type ঠিক (Bank/Cash/Receivable/Payable...)
□  Is Group vs Ledger ঠিক
□  Code Convention মেনেছি (1=Asset, 4=Income...)

Taxes—

□  Sales VAT Template: Type=On Net Total, Rate=15, Account Head=VAT Payable
□  Purchase VAT Template: Type=On Net Total, Rate=15, Account Head=Input VAT
□  Test Invoice-এ Tax Line সঠিক Account-এ গেছে দেখেছি
□  Default Tax Template Company-এ সেট
□  বিদেশি Client থাকলে Tax Category বানিয়েছি
```
