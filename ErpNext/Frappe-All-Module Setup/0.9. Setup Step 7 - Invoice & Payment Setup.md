# PART A : Invoice Setup

## 1. Invoice Print Format

```
ERPNext → Settings → Print Format

↓

Sales Invoice-এর জন্য Custom Print Format বানাও
```

```
এখানে Check করো —

   ✅ Company Logo বসে আছে
   ✅ VAT/TIN Number ছাপছে
   ✅ Payment Terms নিচে আসছে
   ✅ Bank Details Footer-এ আছে ← এটা না থাকলে
      Customer টাকা পাঠাবে কোথায়?
```

> **🚨 Invoice-এ Bank Details না থাকলে Customer-এর Payment আটকে যায় — "কোন Account-এ পাঠাব?" জিজ্ঞেস করতে করতে ১৫ দিন চলে যায়।**

## 2. Invoice-এর Default Terms

```
ERPNext → Selling → Settings

→ Default Terms and Conditions
```

```
লিখে দাও —

   "Payment due within 30 days of invoice date.
    Late payment subject to 2% monthly interest.
    All disputes subject to Dhaka jurisdiction."
```

```
করলে কী হয়:
   ✅ প্রতিটা Invoice-এ নিজে যায়
   ✅ ঝগড়া হলে তোমার পক্ষে লিখিত প্রমাণ

না করলে: মুখের কথা — Court-এ কাজ করে না
```

## 3. Invoice Numbering / Naming Series

```
ERPNext → Settings → Naming Series

↓

Sales Invoice → SINV-.YYYY.-######

```

```

না করলে/হাতে বদলালে:
   Audit-এ গ্যাপ দেখালে "মাঝের Invoice-গুলো কোথায়?" জিজ্ঞেস করবে
```

# PART B : Mode of Payment & Payment Gateway

## কী জিনিস

```
Invoice-এর সাথে Payment Link/QR যায়
→ Customer Click করেই Pay করে
→ Payment নিজে ERPNext-এ ঢুকে Reconcile হয়ে যায়
```

## কোথায়

```
ERPNext → Accounting → Mode of Payment
ERPNext → Integrations → Payment Gateway (যদি App থাকে)
```

## Setup Steps

```
১. তোমার দেশে চলা Gateway বেছে নাও
   (Stripe / SSLCommerz / bKash Gateway / PayPal)

২. Gateway-এর Website থেকে API Key নাও

৩. ERPNext-এ Payment Gateway Account বসাও

৪. প্রথমে Test Mode-এ চালাও

৫. Test Payment সফল হলে Live Mode
```

```
করলে কী হয়:
   ✅ Payment ২-৩ গুণ দ্রুত আসে
   ✅ Auto Reconcile — Accounting-এ হাত লাগে না

না করলে কী হয়:
   Manual Bank Transfer-এ চলে — কাজ চলে, ধীরে

মনে রাখবে:
   ⚠️ প্রতিটা Transaction-এ Gateway Fee (১.৫-৩%)
      → হিসাব করে দাম ঠিক করো
   ⚠️ Test Mode থেকে Live করতে ভুলো না —
      নইলে Customer Pay করছে, টাকা যাচ্ছে না
```

# PART C : Payment Follow-up (পাওনা আদায়ের System)

ERPNext-তে Odoo-র মতো Built-in "Follow-up Levels" নেই, কিন্তু —

```
Option 1: Email Alert / Notification
   → Due Date পার হলে Auto Email

Option 2: Daily/Weekly Reminder Report
   → Accounts Receivable Report দিয়ে
     কার কত দিন Due বের করো

Option 3: Custom App / Server Script
   → বড় Operation-এর জন্য
```

```
করলে কী হয়:
   ✅ কেউ ভুলে গেলে System মনে করিয়ে দেয়
   ✅ পুরোনো পাওনা জমে থাকে না

না করলে:
   ❌ ৬০ দিনের পাওনা চোখেই পড়ে না
   ❌ বছর শেষে ডুবে যাওয়া পাওনার পাহাড়
```

> **Cash Flow-এর জন্য এটাই সবচেয়ে দামি Setup। মাসে একবার Accounts Receivable Report দেখলেই ব্যবসা নিশ্চিত।**

# Common Mistakes

❌ Invoice-এ Bank Details না দেওয়া — Payment আটকে থাকে।

❌ Terms ফাঁকা রাখা — ঝগড়ার সময় হাতে কিছু নেই।

❌ Payment Gateway Test Mode-এ ভুলে যাওয়া — টাকা আসছে না কেন বোঝা যায় না।

❌ Naming Series হাতে বদলানো — Audit-এ গ্যাপ ধরা পড়ে।

❌ Follow-up Setup না করা — পাওনা ডুবে যায় চুপচাপ।

❌ Customer-এ Payment Terms Default না দেওয়া — Due Date হারায়।

❌ Gateway Fee হিসাব না করা — লাভের হিসাব ভুল।

# Checklist

```
Invoice—

□  Print Format-এ Logo + TIN + Bank Details + Terms
□  Default Terms লেখা
□  Email/Portal Send Test করেছি
□  Naming Series ঠিক (হাতে ছোঁনি)

Payment—

□  Mode of Payment: Bank, Cash, Card
□  Gateway বাছাই + API Key বসানো
□  Test Mode-এ Test Payment সফল
□  Live Mode-এ স্যুইচ করেছি 🚨
□  Payment Terms Customer Profile-এ Default

Follow-up—

□  Email Alert বা Weekly Report সেটআপ
□  Accounts Receivable Report নিয়মিত দেখার Plan

Final Test—

□  Invoice → Send → Pay → Paid পুরো Cycle ✅
```
