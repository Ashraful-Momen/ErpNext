# Setup Step 2 : Company & General Settings — ERPNext 16

**Series: ERPNext 16 Perfect Setup (Step 2 of 11)**

> **Company Setup মানে শুধু নাম-ঠিকানা দেওয়া না। এখানের প্রতিটা Field পরে Invoice, Tax Report, Legal Document — সব জায়গায় যায়। একটা ভুল = শত শত Document-এ ভুল।**

---

# কোথায় যাবে

```
ERPNext → Settings → Company

↓

তোমার Company-তে Click
```

---

# প্রতিটা Field — কী / কেন / না করলে কী হয়

## 1. Company Name

```
কী:        তোমার Company-র Legal নাম

কেন:       প্রতিটা Invoice, Bill, Report-এর
          উপরে এই নাম ছাপবে
```

```
করলে:      সব Document Professional দেখাবে

না করলে:   Invoice-এ "Your Company" লেখা যাবে
          → Client-এর চোখে অপ্রফেশনাল
          → Tax Authority-র কাছে অবৈধ Document
```

> **⚠️ Trade License/TIN-এ যে নাম, হুবহু সেই নাম দাও। Short নাম দিলে Legal Document মিলবে না।**

---

## 2. Abbreviation (খুব গুরুত্বপূর্ণ)

```
কী:      Company-র ছোট নাম (যেমন ATL)

কেন:     ERPNext-র সব Account, Warehouse, Cost Center-এ
         এই Abbreviation Auto যোগ হয়

         যেমন: Cash - ATL, Stock - ATL
```

```
ভুল দিলে:
   ❌ সব Account-এর নামে অদ্ভুত Abbreviation চলে আসবে
   ❌ পরে বদলানো কঠিন
```

---

## 3. Address (Street, City, Zip, Country)

```
কী:        Company-র ঠিকানা

কেন:       ৩টা জায়গায় লাগে —
          ১. Invoice PDF-এ ছাপে
          ২. Tax Report-এ যায়
          ৩. Country দেখে ERPNext-র
             অনেক Behavior ঠিক হয়
```

```
Country সঠিক না দিলে:
   ❌ ভুল Tax Rule চলতে পারে
   ❌ ভুল Report Format আসতে পারে
   ❌ Currency-তে সমস্যা
```

---

## 4. VAT / Tax ID (TIN)

```
কী:        সরকারের দেওয়া Tax নম্বর
          (বাংলাদেশে: BIN/TIN)
```

```
করলে কী হয়:
   ✅ প্রতিটা Invoice-এ Auto ছাপে
   ✅ Tax Return-এর সময় Ready থাকো

না করলে কী হয়:
   ❌ Customer তোমার Invoice দিয়ে
      VAT Adjustment নিতে পারবে না
   ❌ Audit-এ জরিমানা
```

> **এটা Setup-এর সবচেয়ে গুরুত্বপূর্ণ ৩টা Field-এর একটা। এখনই দাও।**

---

## 5. Default Currency 🚨

```
কী:        Company-র মূল মুদ্রা
          (সব Account-এর Balance এই মুদ্রায়)
```

```
করলে:      সব Report সঠিক মুদ্রায় আসে

ভুল দিলে কী হয়:
   ❌ প্রথম Entry Post হওয়ার পর
      Currency বদলানো প্রায় অসম্ভব
   ❌ সব Balance ভুল মুদ্রায় জমা হয়ে যাবে
   ❌ শেষ সমাধান: নতুন Site
```

> **🚨 RED ALERT: প্রথম Transaction-এর আগে এই Field দুইবার Check করো। এটাই Setup-এর সবচেয়ে ভয়ংকর ভুল।**

---

## 6. Company Logo

```
কী:        Invoice/Report-এর উপরে যে Logo ছাপে

করলে:      Client-এর কাছে Brand-এর প্রতি আস্থা বাড়ে

না করলে:   Invoice-এ ফাঁকা জায়গা / Default Logo
          → ছোট Company ভাববে
```

```
Tips: পরিষ্কার PNG, সাদা Background, ছোট File Size
```

---

## 7. Email / Phone / Website

```
কী:        Invoice-এর Footer-এ Contact হিসেবে যায়

করলে:      Client প্রশ্ন থাকলে সরাসরি যোগাযোগ করে
          → Payment দ্রুত আসে

না করলে:   Client উত্তর খুঁজে পায় না
          → Payment আটকে যায়
```

---

## 8. Default Accounts (Company-এ)

```
ERPNext → Company → Default Accounts Section
```

```
Default Receivable Account    → Debtors
Default Payable Account       → Creditors
Default Bank Account          → Bank
Default Cash Account          → Cash
Default Inventory Account     → Stock In Hand
Default Cost of Goods Sold    → Cost of Goods Sold
Default Income Account        → Sales
Default Expense Account       → Expenses
```

```
করলে কী হয়:
   ✅ নতুন Customer/Vendor/Item বানালে
      এই Account-গুলো Auto বসে
   ✅ Invoice/Bill-এ Account Select-এর ঝামেলা কমে

ভুল থাকলে কী হয়:
   ❌ সব Invoice-এর Receivable ভুল Account-এ
   ❌ Aged Report ভুল
   ❌ Balance Sheet ভুল
```

> **🚨 Localization-এ যেটা এসেছে সেটাই সাধারণত ঠিক। না বুঝে হাত দিও না। তবে একবার খুলে দেখে নাও কোন Account বসে আছে।**

## 9. Fiscal Year (আলাদা DocType)

```
ERPNext → Accounting → Fiscal Year → New
```

```
Fiscal Year Name  → FY 2026-27
Year Start Date   → ০১-০৭-২০২৬
Year End Date     → ৩০-০৬-২০২৭
```

```
করলে কী হয়:
   ✅ Report সঠিক Period-এ আসে
   ✅ বছর শেষে Period Closing Voucher সঠিক দিনে কাজ করে
   ✅ Tax Period মিলে যায় সরকারের সাথে

না করলে / ভুল করলে:
   ❌ জুলাই–জুন Company-র Report
      জানুয়ারি–ডিসেম্বর ধরে আসবে
   ❌ Year-End Closing গুলিয়ে যাবে
```

> **বাংলাদেশে অধিকাংশ Company: জুলাই–জুন। তোমার Tax Advisor-কে জিজ্ঞেস করে নিশ্চিত হয়ে দাও।**

## 10. Multi Company চালু করবে?

```
ERPNext → Company → New
```

```
একটাই Company হলে:
   → শুধু একটা Company রাখো

একাধিক Company হলে:
   → প্রতিটা Company আলাদা Setup

```

# Common Mistakes

❌ Currency ভুল দেওয়া — Setup-এর সবচেয়ে ভয়ংকর ভুল।

❌ Trade License-এর নামের বদলে অন্য নাম দেওয়া।

❌ VAT Number পরে দেব ভেবে রেখে দেওয়া — প্রথম Invoice-এই লাগবে।

❌ Fiscal Year এলোমেলো রাখা — Tax Period গুলায়।

❌ Default Accounts না বুঝে বদলে দেওয়া।

❌ Abbreviation পরে বদলানোর চেষ্টা — Account/ Warehouse-এর নাম গুলিয়ে যায়।

❌ Logo-তে বড়/অস্পষ্ট File দেওয়া — Invoice PDF ভারী হয়।
