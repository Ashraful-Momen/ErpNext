# Chapter 1 : আগে বুঝো — ERPNext-এর Module ব্যবস্থা

Odoo-র মতো ERPNext-এ আলাদা আলাদা App Install করার দরকার নেই। **ERPNext = একটা App, তার ভিতরে অনেক Module।**

```
ERPNext App
├── Accounts (Accounting)
├── Stock (Inventory)
├── CRM
├── Selling
├── Buying
├── HR
├── Payroll
├── Projects
├── Manufacturing
├── Support
└── ...
```

> **তুমি ERPNext Install করলেই সব Module Database-এ আসে। শুধু User-দের কোন Module দেখাবে সেটা Role Profile / Module Profile দিয়ে ঠিক করো।**

# Chapter 2 : বাধ্যতামূলক Module (সবার জন্য)

## 1. Accounts (Accounting)

```
কী পাবে:
   COA, Journal Entry, GL Entry, Sales/Purchase Invoice,
   Payment Entry, Report — পুরো Accounting

না থাকলে: অবশ্যই কিছুই হবে না। এটাই Core।
```

> **Accounts Module ছাড়া ERPNext-এর কোনো অর্থ নেই।**

## 2. CRM / Selling / Buying

```
CRM     → Lead, Opportunity, Customer
Selling → Quotation → Sales Order → Sales Invoice
Buying  → Purchase Order → Purchase Receipt → Purchase Invoice
```

```
না থাকলে:
   → সরাসরি Invoice বানাতে হবে
   → Quotation/Order Track হবে না
   → 3-Way Matching পাবে না
```

## 3. Stock (Inventory) — যদি পণ্য বিক্রি করো

```
কী পাবে:
   Warehouse, Stock Ledger Entry, Automatic COGS Entry

কেন করবে:
   পণ্য ঢুকলেই Entry, বের হলেই COGS
   → Profit নিজে বের হয়

না থাকলে:
   Inventory হিসাব হাতে করতে হবে
   → COGS ভুল, Profit ভুল
```

```
⚠️ শুধু Service বিক্রি করলে (যেমন Software/Consulting)
   এই Module লাগবে না — User-দের Access থেকে বাদ দাও।
```

## 4. HR / Payroll — ঐচ্ছিক

```
কী: Employee Master, Attendance, Salary Slip, Payroll Entry

কখন করবে: Salary/Payroll System বানাতে চাইলে

না করলে: Salary Manual Journal Entry দিয়েই চলবে
```

# Chapter 3 : Module Enable/Disable (Show/Hide)

```
ERPNext → Settings → Show or Hide Modules

↓

কোন Module কোন User-এর Dashboard-এ দেখাবে সেটা ঠিক করো
```

```
করলে কী হয়:
   ✅ Sales Team-এর Menu-তে শুধু Selling আর CRM থাকে
   ✅ Accountant-এর Menu-তে Accounts + Reports
   ✅ Junior User ভুল Module-এ ঢুকতে পারে না

না করলে:
   ❌ সবার সামনে ২০টা Module-এর Menu
   ❌ ভুলে Manufacturing-এ Entry ঢোকে
```

# Chapter 4 : Custom Apps — Frappe Ecosystem

ERPNext-এ Odoo-র OCA-এর মতো "Community Apps" আছে —

```
১. Frappe Cloud Marketplace
   → app.frappe.io/marketplace
   → এক ক্লিকে Install

২. Custom App (GitHub থেকে)
   → bench get-app
   → bench --site site.name install-app app_name

৩. নিজের বানানো App
   → bench new-app my_app
```

> **⚠️ সবসময় Check করো App-টা ERPNext v16 / Frappe v16-এর জন্য আছে কিনা। পুরোনো Version-এর App জোর করে বসালে System ভাঙবে।**

# Common Mistakes

❌ অদরকারি Module সব User-এর Menu-তে রেখে দেওয়া।

❌ Service Company-তে Stock Module সবার জন্য Enable রাখা।

❌ Custom App Version না দেখে বসানো।

❌ Core Setup না করে Custom App Install করা — Conflict হতে পারে।

❌ "কোনোদিন লাগতে পারে" ভেবে অদরকারি App Install করা।

# Checklist

```
□  ERPNext Site Ready

□  Company Create করেছি (দেশ সঠিকভাবে Select)

□  প্রয়োজনীয় Module-গুলো User-দের দেখাবে

□  Accounts Module সব Accountant User-এর আছে

□  Selling/Buying Module Sales/Purchase Team-এর আছে

□  Stock Module — পণ্য থাকলেই Enable

□  HR/Payroll — লাগলে Enable

□  অদরকারি Module বন্ধ (Hide) করেছি

□  কোনো Custom App Install করার আগে Version Check করেছি
```
