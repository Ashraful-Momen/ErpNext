**Series: ERPNext 16 Perfect Setup (Step 3 of 11) — File 0.5**

> **একটা Company-র তিনটা অফিস — ঢাকা, চট্টগ্রাম, সিলেট। প্রতিটার আলাদা Stock, আলাদা Sales, আলাদা Manager। কিন্তু মালিক এক, Tax এক, Report এক। ERPNext-এ এই "আলাদা কিন্তু এক" সমস্যার সমাধান "Accounting Dimensions" আর Warehouse।**

# Chapter 1 : আগে বুঝো — Branch কী, কী না

## Real Life Story

```
তোমার Software Company-র Head Office ঢাকায়।

নতুন অফিস খুললে চট্টগ্রামে —
   আলাদা Team
   আলাদা ছোট Stock (Laptop, Accessories)
   নিজের Client-দের Invoice
```

প্রশ্ন —

**চট্টগ্রামকে কি আলাদা Company বানাবো?**

```
না!

কারণ —
   আইনি সত্তা একটাই (একটাই TIN/VAT)
   মালিক এক
   Profit হিসাব এক
```

চট্টগ্রাম হলো —

# Branch / Location

```
Company  → আইনি সত্তা (Tax, Report, Balance Sheet)

Branch   → Company-র নিচের Operating Unit
          (নিজের Stock, নিজের Sales, নিজের Manager)
```

---

## Branch বনাম Multi Company — কোনটা কখন

| বিষয় | Branch / Dimensions | Multi Company |
|---|---|---|
| আইনি সত্তা | একটাই | আলাদা আলাদা |
| TIN/VAT Number | একটাই | আলাদা |
| COA / Tax | Shared | আলাদা |
| Report | একসাথে + Branch-ভিত্তিক | আলাদা + Consolidation |
| Stock | আলাদা করা যায় | পুরো আলাদা |
| কখন | একই ব্যবসার অনেক অফিস | আলাদা আইনি ব্যবসা |

> **Rule: একটাই Trade License হলে → Branch/Dimensions। আলাদা License হলে → Multi Company।**

# Chapter 2 : ERPNext-তে Multi-Location কীভাবে কাজ করে

ERPNext-এ Odoo-র "Branch"-এর direct equivalent নেই। এর বদলে ব্যবহার করা হয় —

```
১. Warehouse        → Stock-এর Location
২. Cost Center      → Income/Expense Track
৩. Department       → HR/Operational Track
৪. Project          → Project-ভিত্তিক Track
৫. Custom Dimension → নিজের ইচ্ছামতো Tag
```

## Accounting Dimensions

```
ERPNext → Accounting → Accounting Dimensions

↓

Enable করো:
   Cost Center
   Department
   Project

আর Custom Dimension বানাও:
   Branch (যদি Warehouse/Cost Center যথেষ্ট না হয়)
```

```
কী Shared থাকে:
   ✅ COA, Tax, Fiscal Year, Currency
   ✅ Customer/Vendor (Party)
   ✅ Item Catalog

কী আলাদা করা যায়:
   ✅ Warehouse/Stock
   ✅ Sales Order / Invoice (Dimension Tag সহ)
   ✅ User Access (কে কোন Cost Center দেখবে)
   ✅ Dimension-ভিত্তিক Report
```

# Chapter 3 : Warehouse দিয়ে Branch আলাদা করা

```
প্রতিটা Branch-এর নিজের Stock চাইলে
→ প্রতিটা Branch-এ আলাদা Warehouse বানাও
```

```
Stock → Warehouse → New

   Warehouse Name  → CTG Warehouse
   Company         → Ashraful Tech Ltd
   Parent Warehouse → All Warehouses - ATL
```

```
করলে কী হয়:
   ✅ ঢাকার Stock আর CTG-র Stock আলাদা দেখা যায়
   ✅ CTG-র Sales Order → CTG Warehouse থেকে Deliver

না করলে কী হয়:
   ❌ সব Stock এক জায়গায় মিশে যায়
   ❌ কোন Branch-এ কী আছে — কেউ জানে না
```

> **Rule: Branch আছে + Stock আছে = প্রতি Branch-এ আলাদা Warehouse।**

# Chapter 4 : Cost Center দিয়ে Profit Track করা

```
ERPNext → Accounting → Cost Center → New

   Cost Center Name  → CTG Branch
   Parent Cost Center → All Cost Centers - ATL
```

```
প্রতিটা Invoice/Bill-এ Cost Center Tag দাও
→ Report-এ Branch-ভিত্তিক Income/Expense/Profit ✅
```

```
করলে কী হয়:
   মালিক জিজ্ঞেস করলে "CTG Branch লাভে আছে?"
   → ১ মিনিটে উত্তর
```

# Chapter 5 : User Access ঠিক করো

```
ERPNext → Users and Permissions → User

↓

User খোলো → Allowed Companies / Restrictions
```

ERPNext-তে Odoo-র মতো "Allowed Companies" আছে, কিন্তু Branch-ভিত্তিক Access সরাসরি নেই। তার বদলে —

```
Option 1: Warehouse Restriction
   → CTG Manager শুধু CTG Warehouse দেখে

Option 2: Cost Center Restriction (Permission Rule দিয়ে)
   → Server Script/Permission Rule দিয়ে Filter
```

```
যেমন —
   CTG Manager → শুধু CTG Warehouse + CTG Cost Center
   Head Office Accountant → সব
   তুমি (Team Lead) → সব
```

# Chapter 6 : Custom Accounting Dimension (Branch)

যদি Warehouse আর Cost Center যথেষ্ট না হয় —

```
ERPNext → Accounting → Accounting Dimension → New

   Dimension Name → Branch
   Reference Document Type → Branch (HR DocType)
```

```
তারপর প্রতিটা Transaction-এ Branch Field Auto আসবে।
```

> **Custom Dimension বানালে Reporting আরো সুন্দর হয়, কিন্তু যত কম Dimension তত ভালো।**

# Chapter 7 : Branch কখন বানাবে না

```
❌ একটাই অফিস → Branch দরকার নেই

❌ ভার্চুয়াল Team (সবাই Remote, এক জায়গা থেকে কাজ)

❌ শুধু Department আলাদা করতে চাইলে
   → ওটা Branch না, Department / Cost Center
```

> **Branch মানে Physical Operating Unit — নিজের Stock/Team/Client থাকে এমন জায়গা।**

# Common Mistakes

❌ Branch-কে আলাদা Company বানিয়ে ফেলা — COA/Tax দ্বিগুণ Setup লাগে, Consolidation ঝামেলা।

❌ প্রতি Branch-এ Warehouse না দেওয়া — Stock মিশে যায়।

❌ সব User-কে সব Warehouse Access দেওয়া — ভুল Branch-এ Entry ঢোকে যায়।

❌ Branch-ভিত্তিক হিসাব চাইলেও Cost Center Setup না করা — পরে Report পাওয়া যায় না।

❌ অদরকারি Custom Dimension বানানো — Report slow হয়, User confused হয়।

❌ Cost Center Tag Invoice-এ বাধ্যতামূলক না করা — User ভুলে দেয় না।

# Checklist

```
□  সিদ্ধান্ত নিয়েছি: Branch, না Multi Company

□  প্রতিটা Branch-এর জন্য Warehouse বানিয়েছি

□  প্রতিটা Branch-এর জন্য Cost Center বানিয়েছি

□  প্রয়োজনে Department বানিয়েছি

□  Custom Dimension (Branch) — শুধু প্রয়োজনে

□  User-দের Warehouse/Cost Center Access ঠিক করেছি

□  Invoice-এ Cost Center বাধ্যতামূলক (Mandatory) করেছি

□  Test: CTG Warehouse Select করে Invoice বানিয়ে দেখেছি

□  Test: CTG Cost Center Report-এ শুধু CTG Data দেখাচ্ছে
```
