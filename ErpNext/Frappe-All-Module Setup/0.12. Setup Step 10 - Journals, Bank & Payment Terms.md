# PART A : Journal Entry Type

## ERPNext-এ Odoo-র Journal-এর Equivalent

```
ERPNext → Accounting → Journal Entry

↓

Voucher Type:

Journal Entry          → সাধারণ Manual Entry
Bank Entry             → Bank জড়িত Entry
Cash Entry             → Cash জড়িত Entry
Contra Entry           → Bank ↔ Cash Transfer
Opening Entry          → Opening Balance
Depreciation Entry     → Asset-এর অবচয়
Exchange Rate Revaluation → Currency Rate ঠিক
Inter Company Journal Entry → Multi-company
Deferred Revenue       → অগ্রিম আয়
Deferred Expense       → অগ্রিম খরচ
Reversal Journal Entry → উল্টো Entry
```

> **Odoo-র মতো আলাদা Journal Master Create করার দরকার নেই। Voucher Type Select করলেই হয়।**

---

## Journal Entry-এর প্রতিটা Field

### 1. Voucher Type

```
কী:      এই Entry-র প্রকার

কেন গুরুত্বপূর্ণ:
   Type-ই ঠিক করে এই Entry-র ব্যবহার
   Opening Entry-এ is_opening=1 Auto হয়
```

### 2. Posting Date

```
কী:      কোন দিনের Entry

ভুল দিলে: Report-এর Period গুলিয়ে যায়
```

### 3. Accounts Table (Journal Entry Account)

```
Account        → COA থেকে
Party Type     → Customer / Supplier
Party          → নির্দিষ্ট Customer/Vendor
Debit / Credit → Amount
Cost Center    → কোন Branch/Project
```

### 4. Difference

```
Total Debit − Total Credit = 0 হতে হবে

শূন্য না হলে ERPNext Submit করবে না
```

# PART B : Bank Account Setup

## নতুন Bank Account যোগ করা

```
ERPNext → Accounting → Bank Account → New
```

## প্রতিটা Field

### Account Name

```
কী:      COA-তে কী নামে দেখাবে
         যেমন: Bank DBBL - ATL
```

### Bank

```
কী:      কোন Bank
করলে:    Bank Details Track করা যায়
```

### Account Number

```
কী:      Bank-এর আসল Account Number
কেন:    Statement Import-এ Match করতে লাগে
ভুল দিলে: Statement Line Match হবে না
```

### Default Account

```
কী:      এই Bank Account-এর COA Link

ERPNext Auto Suggest করে:
   → COA-তে "Bank DBBL - ATL" নামে Account তৈরি

ভুল দিলে:
   ❌ Payment Bank-এ গেল, Entry অন্য Account-এ
   ❌ Bank Balance কখনো মিলবে না
```

# PART C : Mode of Payment

```
ERPNext → Accounting → Mode of Payment
```

```
Mode of Payment = টাকা দেওয়ার মাধ্যম

যেমন:
   Cash
   Bank Transfer
   Card
   Cheque
   bKash
```

```
প্রতিটা Mode-এ Default Account দিতে হয়:

   Cash          → Cash Account
   Bank Transfer → Bank DBBL Account
   Card          → Bank Account
   Cheque        → Bank Account
```

```
করলে কী হয়:
   ✅ Payment Entry-এ Mode Select করলে Account Auto আসে
   ✅ Bank Reconciliation সহজ

না দিলে:
   ❌ প্রতিটা Payment-এ হাতে Account Select
   ❌ ভুল Account-এ Entry যায়
```

# PART D : Payment Terms Template

## কোথায়

```
ERPNext → Accounting → Payment Terms Template
```

## কী জিনিস

```
Invoice-এ কবে টাকা দিতে হবে — তার নিয়ম
→ এটা দিলে Due Date নিজে বের হয়
→ Due Date থেকেই Accounts Receivable বানে
```

## Ready থাকে

```
Net 30
Net 15
Due on Receipt
```

## নিজের বানানো — Example

### Example 1 : 50% Advance + 50% in 30 Days

```
Template Name: 50% Advance, 50% Net 30

Line 1: 50% → Due: Day 0 (Immediately)
Line 2: 50% (Balance) → Due: Day 30
```

```
করলে কী হয়:
   Invoice-এ দুইটা Due Date নিজে ভাগ হয়ে যায়
   → $10,000-এর Invoice-এ $5,000 আজকের Due,
     $5,000 ৩০ দিন পরের Due
```

### Example 2 : Software Company-র Classic

```
Template Name: Net 30
Line: 100% → Due: 30 Days after Invoice Date
```

## কোথায় বসবে

```
দুই জায়গায় Default দেওয়া যায়:

১. Customer-এর Profile-এ
   → ওই Customer-এর সব Invoice-এ নিজে আসবে ✅

২. Invoice বানানোর সময় হাতে
   → Rule: Customer-এর Profile-এ বসিয়ে দাও।
     হাতে বসালে একদিন ভুলে যাবেই।
```

```
না দিলে কী হয়:
   ❌ Due Date থাকে না
   ❌ Accounts Receivable অর্থহীন
   ❌ কার টাকা কবে আসবে — কেউ জানে না
```

# Common Mistakes

❌ ERPNext-এ আলাদা Journal Master খোঁজা — Journal Entry Type-ই কাজ করে।

❌ Bank Account-এ Default COA Account ভুল দেওয়া।

❌ Mode of Payment-এ Default Account ফাঁকা রাখা।

❌ Payment Terms Customer Profile-এ না দেওয়া — Due Date হারায়।

❌ "Net 30" Template বানিয়ে Line না দেওয়া — Due Date আসে না।

❌ একটা Bank Account-এ দুইটা COA Account লিংক করা — হিসাব মিশে যায়।

# Checklist

```
Journal Entry—

□  Voucher Type বুঝেছি
□  Difference = 0 চেক বোঝা আছে

Bank—

□  প্রতিটা Bank Account আলাদা COA Ledger-এ
□  Account Number সঠিক
□  Dashboard-এ Bank Balance দেখা যাচ্ছে
□  Test Payment → GL Entry ঠিক জায়গায় গেছে

Mode of Payment—

□  Cash, Bank Transfer, Card, Cheque বানানো
□  প্রতিটার Default Account দেওয়া

Payment Terms—

□  Net 30 (বা তোমার Standard) Template বানানো
□  প্রধান Customer-গুলোর Profile-এ Default বসানো
□  Test Invoice-এ Due Date নিজে এসেছে দেখেছি
```
