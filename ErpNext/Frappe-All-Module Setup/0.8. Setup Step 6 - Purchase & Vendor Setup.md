# Chapter 1 : Purchase Flow আগে বুঝো

```
Purchase Order (PO) তৈরি

   ↓ (Supplier-কে পাঠালে)

Supplier মাল পাঠাল

   ↓

Purchase Receipt (মাল Receive — Inventory-তে Auto)

   ↓

Purchase Invoice এলো

   ↓

3-Way Match: PO = Receipt = Bill?

   ↓ (মিললে)

Payment Entry → Paid ✅
```

> **মূল কথা: Bill তখনই Pay করবে, যখন তিনটা কাগজ মিলবে। Setup-এর কাজ — এই Matching Automatic করা।**

## SECTION : Orders

### 2. Purchase Order Required

```
কী:      Purchase Invoice বানাতে আগে PO লাগবে কিনা

চালু করলে: PO → Receipt → Invoice Flow discipline থাকে
বন্ধ করলে: সরাসরি Invoice → দ্রুত, কিন্তু Track কম
```

### 3. Purchase Receipt Required

```
কী:      Purchase Invoice Submit-এর আগে Purchase Receipt লাগবে কিনা

চালু করলে: 3-Way Matching হয়
বন্ধ করলে: সরাসরি Invoice → Stock Track হারায়
```

---

## SECTION : Invoicing

### 4. Bill Based On 🚨

```
কী:      Purchase Invoice কোন Quantity ধরে বানবে?
```

| Option | মানে | কখন |
|---|---|---|
| Purchase Order | PO-তে যা আছে তাই Bill | Service/Advance কেনা |
| Purchase Receipt | যতটা এসেছে ততটাই Bill | পণ্য ✅ |

```
Purchase Receipt করলে কী হয়:
   ✅ ১০টার PO, ৮টা এলো → Bill-এ ৮টাই আসবে
   ✅ বাকি ২টা আসলে পরে আলাদা Bill
   ✅ না আসা মালের টাকা কখনো যায় না
```

```
Purchase Order করলে:
   মাল আসার আগেই পুরো Bill — পণ্যের জন্য বিপদ
```

> **পণ্য কিনলে: Purchase Receipt Base। এটাই 3-Way Matching-এর ভিত্তি।**

# Chapter 3 : 3-Way Matching — বুঝেই চালু করো

## কী

```
তিনটা কাগজ মেলানো —

   ১. Purchase Order  → কী চেয়েছিলে
   ২. Purchase Receipt → কী পেয়েছো
   ৩. Purchase Invoice → কী ধরেছে Supplier
```

## কেন

```
মিললে:      নিশ্চিত হয়ে Pay করো

না মিললে:   "অর্ডার ১০টা, এসেছে ৮টা, Bill ১০টার"
            → আটকে দাও, Supplier-কে জিজ্ঞেস করো
```

## ERPNext-তে কীভাবে কাজ করে

```
Buying Settings-এ:
   Purchase Order Required = Yes
   Purchase Receipt Required = Yes
   Bill Based On = Purchase Receipt

→ Bill তৈরি হয় Receipt থেকে
→ তিনটা নিজে মিলে যায়
→ মিল না থাকলে Quantity-তেই ধরা পড়ে
```

```
করলে কী হয়:
   ✅ বাড়তি Bill কখনো Pay হয় না
   ✅ Fraud/ভুল প্রায় অসম্ভব

না করলে:
   ❌ Supplier যা লিখে দিল তাই Pay
   ❌ বছর শেষে হিসাব মেলাতে গিয়ে আগুন
```

## গুরুত্বপূর্ণ Field

### 1. Name + Address + Tax ID

```

   Tax ID ছাড়া Input VAT Adjust করা যায় না
```

### 2. Supplier Group

```
Raw Material / Services / Electronics
→ Report-এ Group-ভিত্তিক Analysis
```

### 3. Payment Terms

```
Supplier-কে কত দিনে Pay করবে (যেমন: Net 30)

করলে:   Bill-এ Due Date নিজে আসে

```

### 4. Payable Account

```

→ শুধু Check করো, বদলিও না
```

### 5. Bank Details

```
Supplier-এর Bank Account রেখে দাও
→ Payment-এর সময় ভুল Account-এ টাকা যায় না
```

```

করলে কী হয়:
   ✅ Replenishment সঠিক দিনে Order দেয়

না দিলে: Stock ফুরিয়ে যাওয়ার পরে Order যায়
        → মাল আসতে আসতে Customer চলে গেল
```

# Common Mistakes

❌ Bill Based On = Purchase Order রেখে পণ্য কেনা — না আসা মালেরও টাকা যায়।

❌ Purchase Receipt Required বন্ধ রাখা — Stock আর Account মিলে না।

❌ Supplier-এর Tax ID না নেওয়া — Input VAT ফেরত পাবে না।

❌ Payment Terms না দেওয়া — কার Bill কবে Due, হিসাব নেই।

❌ Lead Time ফাঁকা — Replenishment ভুল দিনে Order দেয়।

❌ Supplier Price List না দেওয়া — প্রতিবার ভিন্ন দাম।

❌ Receipt না করে Purchase Invoice Submit করা — Stock আর Account মিলে না।
