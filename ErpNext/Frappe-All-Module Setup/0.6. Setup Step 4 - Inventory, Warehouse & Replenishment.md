# Chapter 2 : Warehouse Setup

## কোথায়

```
ERPNext → Stock → Warehouse
```

## Default-এ একটা থাকে

```
Company Create করলেই একটা Warehouse থাকে
(তোমার Company-র নামে — যেমন: All Warehouses - ATL)

→ ছোট ব্যবসা হলে এটাই Root
```

## প্রতিটা Field

### 1. Warehouse Name + Parent Warehouse

```
Warehouse Name  → CTG Warehouse
Parent Warehouse → All Warehouses - ATL

→ Tree Structure হয়
```

### 2. Company / Branch

```
কোন Company-র Warehouse
→ ভুল দিলে ভুল Company-র Stock দেখাবে
```

### 3. Address

```
গুদামের ঠিকানা
→ Delivery Document-এ লাগে
```

## একাধিক Warehouse কখন?

```
✅ একাধিক Branch/শহরে Stock থাকলে
✅ Main Stock আর Showroom Stock আলাদা রাখতে চাইলে
❌ একটাই গুদামে শুধু Shelf আলাদা করতে চাইলে
   → ওটা Warehouse না, Location (ERPNext-এ Warehouse-এর Child Warehouse)
```

# Chapter 3 : Item Setup

```
ERPNext → Stock → Item → New
```

## গুরুত্বপূর্ণ Field

### 1. Item Name + Item Code

```
Item Code → Unique ID (যেমন: LAPTOP-DELL-001)
Item Name → মানুষের পড়ার নাম
```

### 2. Item Group 🚨

```
Category-এর মতো —
Electronics > Laptop
Services > Consulting
```

### 3. Stock Related — Item Type

```
Maintain Stock = Yes   → Stock Track হবে (পণ্য)
Maintain Stock = No    → Service/Non-Stock
```

```
ভুল দিলে:
   Service Item-এ Maintain Stock=Yes → অদরকারি Stock Entry
   পণ্যে Maintain Stock=No → Stock জানা যাবে না → COGS ভুল
```

### 4. Default Warehouse

```
কোন Warehouse-এ এই Item থাকবে
→ Sales Order-এ Auto Warehouse আসে
```

### 5. Valuation Method 🚨

```
FIFO           → First In First Out
Moving Average → গড় দাম
```

```
কোনটা দেবে:
   দাম ঘনঘন বদলায় → FIFO
   স্থিতিশীল দাম    → Moving Average
```

### 6. Default Income / Expense Account

```
Income Account → Sales Invoice-এ কোন Account-এ Sales যাবে
Expense Account → Purchase Invoice-এ কোন Account-এ খরচ যাবে
```

# Chapter 4 : Stock Settings (Accounting-এর সাথে জোড়া)


```
ERPNext → Stock → Item Group → Select Group

↓

Default Warehouse
Default Income Account
Default Expense Account
```

```
করলে কী হয়:
   ✅ প্রতিটা Stock Move-এ Auto GL Entry
   ✅ COGS নিজে বের হয়

ভুল দিলে:
   ❌ Stock Move হলো, Accounting Entry হলো না
   ❌ মাস শেষে COGS হাতে বসাতে হবে
```

# Chapter 5 : Replenishment (Stock ফুরালে Auto Order)

## Real Life সমস্যা

```
মাউস প্যাড বিক্রি করো।
Stock-এ ৫টা আছে। হঠাৎ ২০টার Order এলো।
→ তুমি জানতেও পারলে না Stock ফুরিয়েছে
→ Customer-কে "নেই" বললে → সে চলে গেল প্রতিযোগীর কাছে
```

## সমাধান — Reorder Level

```
ERPNext → Stock → Reorder Level

→ Item Select
→ Warehouse Select
→ Reorder Level  → ১০ (এর নিচে নামলে Alert)
→ Reorder Qty    → ৫০
```

```
করলে কী হয়:
   ✅ Stock ১০-এর নিচে নামলে
      Material Request Auto তৈরি হয়
   ✅ কখনো Stock-Out হয় না
```

## MTO (Make to Order)

```
Order আসলে তখনই কেনা/বানানো

→ Item-এ "Is Purchase Item" + Sales Order থেকে PO
→ দামি/কম চলা পণ্যের জন্য
```

```
কোনটা কখন:
   নিয়মিত চলা পণ্য → Reorder Level
   দামি/রেয়ার পণ্য → MTO / Manual
```

# Chapter 6 : Opening Stock ঢোকানো

```
ERPNext → Stock → Stock Reconciliation

→ Warehouse Select
→ প্রতিটা Item-এর Actual Quantity বসাও
→ Submit
```

```
✅ Check: Stock In Hand Account-এ Entry গেছে কিনা
```

```
⚠️ মনে আছে Opening Balance-এর ভুল?

   Opening Journal Entry-তেও Inventory দিলে,
   আবার Stock Reconciliation-ও করলে
   → Inventory দ্বিগুণ দেখায়

   সমাধান:
   Automated Inventory হলে Stock Reconciliation দিয়ে ঢোকাও,
   Opening Journal Entry-তে Inventory বাদ দাও
```

# Common Mistakes

❌ Service Company-তে Stock Module সব User-এর জন্য Enable রাখা।

❌ প্রতি Shelf-এর জন্য আলাদা Warehouse — Child Warehouse লাগে।

❌ Item-এ Maintain Stock ভুল দেওয়া।

❌ Item Group-তে Income/Expense Account না দেওয়া — Invoice-এ Account ভুল আসে।

❌ Reorder Level ছাড়া Stock চালানো — Stock-Out হয়েও টের পাও না।

❌ Opening Stock দুই জায়গায় (JE + Stock Reconciliation) ঢোকানো।

❌ Valuation Method না বুঝে FIFO/Moving Average বেছে নেওয়া।
